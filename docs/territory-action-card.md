# 점령지 선택 카드

승인된 HTML 시안의 정보 순서를 산책 지도 `TerritoryActionCard`에 적용한다.

| 상태 | 첫 정보 | 다음 행동 |
| --- | --- | --- |
| 미점유 | 아직 주인이 없어요 | 산책 준비 / 일반 점령 / 강아지 인증 |
| 타인 점유 | 주인 이름·인증 상태·유지 시간 | 서버가 허용한 일반 점령 또는 인증 도전 |
| 내 점유 | 해당 강아지 프로필·이름·유지 시간 | 서버가 허용한 인증 또는 유지 연장 |
| 조회 실패·로그인 필요 | 실패·인증 안내 | 미점유 및 보상으로 대체하지 않음 |

- 카드가 열려 있는 산책 시작 전에는 큰 시작 패널을 접는다. **산책 준비하기**는 선택을 닫아 기존 참여견 선택/시작 패널을 보여주며, 산책이나 점령을 바로 실행하지 않는다.
- 카드 높이는 화면에 비례해 제한하고 내부를 스크롤한다. 다른 장소를 선택하면 스크롤을 초기화한다.
- 주인 사진·견종은 `isOwnedByMe`가 확인되고 로컬 반려견 ID가 일치할 때만 연결한다. 공개 점유 API에 없는 타인 프로필은 발자국으로 표시한다. 이름은 식별키로 사용하지 않는다.
- 시즌 점수·순위·개인별 남은 보상은 현재 점유 API에 없다. 임의 값이나 0점을 넣지 않는다. 상세 설명에서 점수·순위 미제공 상태를 알린다.
- `first-season-rewards-v1` 응답에서만 최대 기본 보상/탈취 보너스 정책을 안내한다. **최대 보상은 이번 행동의 확정 지급액이 아니다.** 인증 업그레이드도 80점으로 고정하지 않는다. 기존 정책·조회 실패에는 첫 시즌 숫자를 표시하지 않는다.
- 인증이 가능하면 사진 버튼을 주 행동으로, 일반 점령을 보조 행동으로 둔다. `canMark`, `canPhotograph`, `readOnly`, 산책 단계 및 피드백을 존중한다. 카드 문구로 허용 조건을 만들지 않는다.
- 현재 온라인 조건은 일반 점령 20m, 인증 촬영 10m이며 GPS 오차를 포함한다. 이번 변경에서 정책·반경·점수 지급 로직은 바꾸지 않는다.
- 북마크는 기존 회원 단위 controller를 그대로 사용한다. 알림 구독을 새로 만들지 않는다.

## 검토 화면

Debug의 `com.daengs.app.ui.walk.TerritoryCardLabActivity`에서 세 상태·산책 중 상태·북마크를 바꿔볼 수 있다. 실제 지도 위에 가상 점유 정보를 표시하며 점령·산책·사진 API를 호출하지 않는다. 공개 점수/순위 확장은 별도 서버 계약이 필요하다.
