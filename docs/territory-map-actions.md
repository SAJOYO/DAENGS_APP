# 점령 게임 2단계 — 산책 지도와 영역표시

제작 계획: [Geo #230](https://github.com/rkbuhtig/DAENGS_geo/pull/230).
기반 모델: [APP #139](https://github.com/SAJOYO/DAENGS_APP/pull/139).
지도 연결: [APP #140](https://github.com/SAJOYO/DAENGS_APP/pull/140).

## 체험 흐름

1. 기존 README대로 지도 키·API 주소를 설정한 debug 앱에서 참여견을 골라 산책을 시작한다.
2. **점령지 보기**를 누른다. 실제 주변 장소 조회 결과 위에 메모리 점유 상태를 결합한다.
3. 선택한 지점이 없으면 현재 산책 위치에서 가장 가까운 장소를 대상으로 보여준다.
   마커를 누르면 그 장소를 대상으로 고정한다. 지도 카메라와 조회 응답의 `distance_m`는
   접근 판정에 사용하지 않는다. 빈 지도를 누르면 명시적 선택이 해제된다.
4. 대상의 반경 안에 들어오면 범위 강조와 짧은 진동이 나타난다. 카드에는 점유 강아지,
   미인증/인증 여부, 영역표시 주체, 현재 가능한 행동을 표시한다.
5. Pin 아이콘의 **영역표시**를 누르면 빈 장소가 대표견의 미인증 영역으로 바뀐다.
   같은 세션의 같은 장소는 다시 점령하지 않는다. 다른 장소로 이동하면 추가 점령할 수 있다.
6. **점령지 숨기기**로 표시를 꺼도 산책 기록과 메모리 점유는 유지된다.

이번 단계는 debug 빌드의 **점령 연습**이다. 실제 사용자들의 점유를 조회하거나 서버에
저장하지 않는다. 점유는 화면 재생성/지도 새로고침 동안 유지되고 프로세스 종료 시 사라진다.
release에는 페이크 액션을 연결하지 않고 기존 장소 읽기를 유지한다. 지도 키나 위치를
임의로 채우거나, 실제 지점에 가짜 경쟁자를 자동 배치하지 않는다.

## 연결 구조

- `WalkTrackingService`가 실제 `activeSessionId`와 `activeDogIds`를 화면 상태에 전달한다.
  화면에서 산책 UUID를 새로 만들지 않는다. 일시정지 중 identity를 유지하고 종료 시 비운다.
- 대표견은 현재 참여 목록의 첫 강아지를 기본값으로 쓰고 카드에서 이름을 보여준다.
  참여견은 산책 시작 시 서비스에 고정된다. 별도 대표견 선택 UX는 이 단계에서 확장하지 않는다.
- `TerritoryGameController`가 기존 장소와 점유 스냅샷을 결합하고 대상별 접근 상태를 만든다.
  미인증·인증 점유와 접근 준비는 독립이다. 초기 점유/정책을 주입해 프리뷰·테스트할 수 있다.
- `WalkViewModel`은 UI 액션 시 **표시했던 장소 ID**를 다시 판정한다. 화면에서 준비였어도
  오래된 위치·권한 해제·일시정지·대상 목록 변경이 있으면 점령하지 않는다.
- `WalkMapPresentation`은 점유 색/라벨, 선택 대상, 준비 여부와 범위를 지도 공급자에 넘긴다.
  Naver renderer는 색·문구·원을 그리며 점령 판정은 수행하지 않는다.
- 영역표시는 기존 `TOILET_MARKING` 등 행동 Pin과 별도다. 영역표시를 했다는 이유로
  배변 기록을 만들거나, 배변 기록으로 점유를 바꾸지 않는다.

## 접근과 아직 연결하지 않은 것

현재 로컬 조정값은 반경 20m, 위치 최신성 10초다. 거리+GPS 오차가 반경 안이어야 하고,
정밀 위치 권한·기록 중 상태·참여견·신뢰 가능한 최신 fix가 필요하다. 모의 위치와
추적 중 속도/정확도 거절 상태는 차단한다. 카드는 매초 최신성을 갱신하며 탭 시에도 재검사한다.
이 값은 온라인 API의 사진 인증 반경 계약을 변경하지 않는다.

사용하는 위치는 산책 서비스의 정확도 필터를 거친 행동 후보 fix다. 화면의 실시간 판정은
로컬 플레이 피드백이며 서버의 canonical 산책 접촉 인증을 대신하지 않는다. 온라인
연결 단계에서는 검증된 접촉 근거로 서버가 최종 확정해야 한다.

인증된 영역에는 사진 필요 안내를 보여준다. 이번 단계에서는 사진 촬영/탈취 버튼을
가짜 성공 처리하지 않는다. 다른 강아지의 미인증 영역도 무사진 탈취 정책을 확정하지
않았으므로 안내만 한다. 다음 3단계에서 같은 시도의 실제 촬영·페이크 사진 판정을 붙인다.

## 검증 범위

타겟은 `TerritoryGameControllerTest`, `WalkViewModelTest`, 기존 Territory 테스트,
`MapScenePolicyTest`와 산책 추적 관련 테스트다. 실제 위치 기반 대상 선택, 점유 유지,
세션 중복, 다중 장소, 시간 경과·권한·일시정지 차단, 지도 표시 정책을 확인한다.
`TerritoryActionCard`에는 Compose Preview를 둔다. 실제 보행 감각·진동·가로/세로 배치는
기기에서 별도 확인해야 한다.
