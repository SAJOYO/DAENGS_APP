# 단일 산책 경로 끝부분 캐시

`WalkSpeedPathCache`는 기존 `paintWalkSpeedPath`를 수정하지 않고 작은 끝부분에 재사용한다. 새 좌표가 붙으면 기존 마지막 선분의 끝 색상과 새 선분이 달라지므로, 그 앞의 문맥 선분 하나를 포함해 계산하고 문맥 출력은 버린다. 안정된 앞부분의 `WalkSpeedPart`는 그대로 공유한다.

## 적용과 무효화

- 이전 경로와 정책/테마가 같고, 기존 좌표/시각 전체가 새 경로의 정확한 앞부분인 경우만 증분 계산한다. 중첩 입력 목록은 불변 snapshot 계약이다.
- 초기 로딩, 앞/뒤 좌표 삭제, 경로 교체, 과거 시각/좌표 정정, 정책/테마 변경은 전체 계산으로 전환한다. 이후 다시 append를 처리할 수 있다.
- 마지막 선분의 출력 개수와 문맥 선분의 출력 개수는 기존 함수로 구한다. 0거리, 속도 미상, 잘못된 시각과 세분화 규칙을 별도 구현으로 복제하지 않는다.
- 3점 이상인 경로에 한 점 추가 시 최대 4점 문맥 창 + 문맥 개수용 2점 + 마지막 개수용 2점을 계산한다. 따라서 계측상 8점/5선분이며, 실제 표시에서 바뀌는 것은 기존 마지막 선분과 새 선분이다.
- 결과는 새 평탄한 목록으로 만든다. 이전 결과를 수정하거나 오래된 목록을 연결한 사슬을 쌓지 않는다. 지도/구간 해제로 저장소 entry가 제거되면 캐시도 함께 해제된다.

## 남는 비용과 범위

기존 접두부가 같은지 검증하고 결과 목록에 앞부분 참조를 복사하는 비용은 O(n)이다. 네이버 SDK에 전체 좌표/색상 목록을 전달하는 비용과 상위 snapshot 투영도 남는다. **한 점 추가 전체가 O(1)이 된 것은 아니다.** 속도·색상 보간 계산량만 끝부분으로 제한한다.

실제 `TrailRecorder` 기본 표시 한도는 5,000점이다. 한도에서 앞쪽 좌표가 잘리는 업데이트는 이번 append 최적화 대상이 아니며 전체 계산한다. 벤치마크의 5,000→5,020점은 append 계산 비용을 분리한 가상 입력이고, 실제 한도를 변경하지 않는다.

## 재현

`WalkRoutePerformanceLabActivity`에 `single=true` 옵션을 추가했다. 기본 4구간 비교는 유지하고, 이 옵션은 단일 1천/5천 좌표에 각각 250ms 간격으로 20점을 추가한다. 지도 초기화 4초, 각 규모 설정 후 2초는 집계에서 제외한다. 가상 좌표만 사용하며 GPS·서버·기록 API를 호출하지 않는다.

```powershell
adb shell am start -S -W -n com.daengs.app.cardpreview/com.daengs.app.ui.walk.WalkRoutePerformanceLabActivity --ez auto true --ez single true
adb logcat -d -s WalkRoutePerf:I '*:S'
```

현재 프로세스 pid로 필터링하고 `DONE`을 확인한다. `edges`는 원본 painter에 전달한 선분 수의 합으로, 문맥/개수 계산의 중복 호출도 포함한다. `points` 역시 호출별 입력 점 수의 합이며 실제 지도에 남긴 좌표 수가 아니다. `prepareMs`는 접두부 검증/끝부분 보간/결과 목록 생성, `sdkMs`는 기존 좌표 변환과 SDK 갱신 경계의 시간이다. 화면 전체 프레임, 상위 snapshot 생성, 모든 내용 비교 비용을 뜻하지 않는다.

## 대상 검증

기존 전체 painter를 기준으로 좌표와 색상 목록의 정확한 동등성을 비교한다. 결정적 난수 입력/여러 테마/배치 추가 외에, 0거리·잘못된 시각·과속·접두부 삭제·기록 교체·시각 정정·정책 변경·기존 출력 불변성과 앞부분 객체 공유를 검사한다. 기존 경로 저장소의 구간 분리/지도 해제도 함께 검사한다.

```powershell
./gradlew.bat :app:testDebugUnitTest --tests com.daengs.app.map.style.WalkSpeedPathCacheTest --tests com.daengs.app.map.provider.naver.WalkRouteOverlayStoreTest --tests com.daengs.app.map.style.WalkStylePolicyTest :app:assembleDebug -PslimAbi=arm64-v8a --max-workers=2 --console=plain
```

별도 폰 패키지는 `-I <preview.init.gradle>`로 `.cardpreview`와 별도 Kakao scheme을 적용한다.
