# 산책 스토리보드 검토 — 첫 화면

진입: 산책 기록 목록 → 산책 상세 → **스토리보드 검토**.

현재 저장된 산책 시작·행동/메모·종료 요약을 시간순 장면으로 제공한다. 핀이 없는 산책도
시작과 종료 요약을 보여준다. geo의 환경·속도·셀로판 분석과 LLM은 아직 연결하지 않았다.
자동 환경 장면이 있는 것처럼 임의의 사실을 만들지 않는다.

- 장면 제목(80자)·본문(2000자) 편집은 행동 원본을 수정하지 않는다.
- 숨김/복원은 검토 구성의 선택이다. 원본을 삭제하지 않는다.
- 근거를 열고 기존 행동/메모 편집창으로 원본을 수정·삭제할 수 있다.
- 편집된 장면의 원본이 바뀌면 사용자 문구를 보존하고 확인을 요구한다.
- 삭제된 원본의 편집 문구는 보존하지만 새 검토본에서 제외한다.
- `이 구성 검토 완료`는 현재 표시 장면·근거 fingerprint의 JSON 사본을 저장한다.
  다음 편집은 이전 완료 사본을 자동 변경하지 않는다. 다음 완료 시 최신 사본으로 대체한다.
  지금은 마지막 완료본 하나를 보관하며 전체 버전 이력·일기 판본은 구현하지 않았다.
- AI 일기 생성 버튼은 미연결 상태로 비활성화했다. 완료가 AI 호출을 의미하지 않는다.

저장은 Room v8 `walk_storyboard`의 세션별 JSON이다. v7→8은 새 표만 추가하며 기존 기록을
보존한다. FK cascade로 산책 삭제/계정 로컬 기록 삭제 시 함께 제거된다. 읽기·쓰기 시
현재 계정의 세션인지 확인한다. 서버 동기화는 아직 없으므로 다른 기기 복원은 지원하지 않는다.

향후 서버의 근거 조각·장면 계약을 연결할 때에도 사용자 편집과 근거를 분리하고,
일기 생성 요청은 명시적으로 완료한 스토리보드 버전을 입력으로 받는다.

검증: `:app:assembleDebug :app:testDebugUnitTest` 성공, 966개 테스트 통과.
새 테스트는 문구 보존·원본 변경 확인·숨김/복원·삭제 후 snapshot 분리·Room cascade와
Compose 화면의 숨김/복원·근거·검토 완료·AI 비활성 표시를 확인한다. 실기기 검증은 미실시다.
