# 내 주변 수동 조건 검색

연결 API: [DAENGS_dev#358](https://github.com/SAJOYO/DAENGS_dev/pull/358), 엔진: [DAENGS_dev#356](https://github.com/SAJOYO/DAENGS_dev/pull/356).

## 사용 흐름

내 주변의 `조건 선택`에서 지원 조건을 조회한 뒤 업종 1~6개를 선택한다. 모두 만족해야 하는 공통 조건에 주차 가능/불가, 반려동물 전용/전용 아님을 함께 넣을 수 있다. `상관없음`은 필터를 지우며 false와 다르다. 모르는 값은 어느 쪽으로도 추측하지 않는다.

`대안 묶음`은 최대 4개다. 묶음 안은 AND, 묶음 사이는 OR이며 공통 조건도 함께 만족해야 한다. 예를 들어 공통 조건 없이 `(카페 그리고 주차 가능) 또는 (음식점 그리고 반려동물 전용)`을 만들 수 있다. 각 묶음은 업종도 따로 고르고 수정/삭제할 수 있다. 빈 묶음이나 후보 밖 업종, 모순된 조합은 적용되지 않는다.

주차 우선은 별도 선호이며 적용할 업종을 고른다. 필수 조건을 통과한 곳 안에서만 정렬에 쓰인다. `조건 정보가 부족한 곳도 별도로 보기`는 결과를 `조건 충족`과 `확인 필요`로 나눈다. 그룹별 서버 순서를 보존하고, 같은 장소의 중복 카드는 표시 단계에서만 접는다. 결과 개수는 반환된 카드 개수이며 잘린 그룹에는 기존 추가 결과 안내가 나온다. 상세 카드에 판정과 정보 부족 사유/출처를 표시한다.

반경·장소명·검색 위치·선택 반려견은 기존 검색 세션이 공급한다. 필터를 적용한 뒤에도 지도 재검색·현재 위치·반경 변경·반려견 갱신·재시도에 조건이 유지된다. 적용된 업종을 바꿀 때는 조건 편집으로 들어간다. 기본 전체 검색(18업종)은 기존 경로이며, 조건 검색으로 전환하려면 1~6개를 직접 선택해야 한다. 임의로 앞의 6개만 선택하지 않는다.

## 경계와 오류

- `PlaceFilterCriteria`가 공통 조건/OR 분기/선호/미상 정책을 가진다. `PlaceFilterRequest`는 좌표·이름·반려견을 합친 전체 상태와 요청 revision/UUID를 직렬화한다.
- `PlaceApi`가 지원 목록과 검색을 각각 `/v3/places/capabilities`, `/v3/places/search`에 보낸다. 미지원 서버에서는 조건 선택을 켜지 않으며 조건을 누락하는 v2 fallback을 하지 않는다.
- `PlaceDiscoveryController`가 편집을 실행한다. 검증/네트워크 실패면 이전 조건과 결과를 유지한다. 성공 응답의 전체 상태·revision·UUID·그룹·반려견 snapshot/개별 판정을 대조한 뒤 한 번에 적용한다. 취소/더 최신 요청 뒤에 도착한 응답은 버린다.
- `PlaceSessionCoordinator`는 새 업종 조합을 검색 의도에도 반영한다. 조건 해제 후 반경을 바꿨을 때 옛 업종으로 돌아가지 않는다.
- `revision`은 이 앱 세션의 요청 세대다. 서버 CAS나 영구 세션 식별자가 아니다. 앱 프로세스 종료 후 필터 복원은 이번 단계 범위 밖이다.
- 5단계 연결 전까지 적용한 수동 조건을 가진 채 기존 AI 모드로 전환할 수 없다. 조건 전체 해제를 안내한다. 기존 AI 경로로 보내면서 조건을 조용히 버리는 것을 막는다.

## 검증

`PlaceFiltersTest`/`PlaceFilterApiTest`는 wire 계약, 거부 응답, 개별 반려견 판정과 Python 생성 fixture를 대조한다. `PlaceFilterControllerTest`는 원자적 적용, 취소를 무시하는 늦은 전송, 재검색 시 조건 보존을 확인한다. `PlaceFilterUiTest`는 수동 교집합 편집, 미지원 서버, 빈 OR 묶음, 미상 결과 분리를 확인한다. 기존 coordinator·ViewModel·연결 화면·업종 테스트도 영향을 받는 대상으로 실행한다.

`app/src/test/resources/place_filter_wire.json`은 backend의 `tests/place/api/condition_wire.json`과 같은 합성 데이터다. 운영 DB나 실제 반려견 정보를 담지 않는다. UI 렌더 산출물은 `app/build/filter-screenshots/`에 생성하며 커밋하지 않는다. 테스트 명령은 PR 본문의 최신 결과를 참고한다.
