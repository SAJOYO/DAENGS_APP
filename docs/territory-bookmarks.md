# 전봇대 북마크 — APP #278

점령 게임의 **북마크한 전봇대** 메뉴에서 회원이 저장한 장소를 다시 찾는다.
**내 점령지**는 현재 소유 목록이고, 북마크는 소유·인증·시즌과 독립된 개인 저장 목록이다.

## 화면과 동작

- 산책 지도에서 선택한 전봇대 카드와 내 점령지 카드의 ☆로 저장하고 ★로 해제한다.
- 목록은 서버의 최근 저장 순서를 유지하고 저장 시각과 `저장 수 / 한도`를 표시한다.
  초기 정책은 회원당 20개이며 표시 값은 API의 `limit`에서 읽는다.
- 목록의 **지도에서 보기**는 저장한 좌표를 전용 지도에서 선택한다.
  지도에서는 저장한 전봇대를 모아 볼 수 있고, 뒤로 가면 목록으로 돌아간다.
- 지도는 MapHost만 사용한다. 산책 세션, GPS 권한, 위치 추적, 사진 인증을 시작하지 않는다.
- 장소가 사라지거나 위치 조회가 일시 실패해도 저장된 항목과 해제 버튼은 유지한다.
  좌표 없는 항목의 지도 이동만 비활성화한다.
- 북마크 지도는 저장 위치를 표시한다. 소유자·인증 상태를 추정하거나 중립 소유로 표시하지 않는다.
- 알림 기능은 다음 단계다. 현재 북마크는 알림을 구독하지 않는다.

## 서버 계약

선행 PR: [DAENGS_dev #431](https://github.com/SAJOYO/DAENGS_dev/pull/431).

| 요청 | 용도 |
| --- | --- |
| GET `/app/territory/bookmarks` | 회원 전체 목록, `total_count`, `limit` |
| PUT `/app/territory/bookmarks/{site_id}` | 멱등 저장, 요청 본문 없음 |
| DELETE 같은 경로 | 멱등 해제, 요청 본문 없음 |

회원 JWT를 매 요청마다 SessionProvider에서 얻는다. ID는 경로와 내부 선택키로만 쓰며 화면에 노출하지 않는다.
401은 재로그인, 409 `bookmark_limit_reached`는 한도 초과,
404 `territory_site_not_found`는 사라진 장소,
503 `territory_sites_unavailable`는 장소 조회 실패로 안내한다.
엔드포인트 자체가 없는 일반 404는 기능 준비 중으로 표시하며 빈 목록으로 바꾸지 않는다.

## 상태와 복구

`TerritoryBookmarkProvider`가 회원 로그인 생애 `AccountScope`별 컨트롤러를 제공한다.
토큰 회전은 같은 생애를 유지하지만, 로그아웃·다른 회원 로그인·같은 회원 재로그인은 새 컨트롤러로 바뀐다.
전체 앱 화면을 계정 키로 재생성하지 않고 북마크 상태와 선택만 교체한다.

목록 조회와 변경을 한 번에 하나씩 수행한다. 요청 중 중복 탭과 새로고침은 추가 요청을 만들지 않는다.
PUT/DELETE 뒤에는 성공·실패 모두 GET으로 저장 상태를 다시 맞춘다.
응답이 유실되었더라도 서버에 반영된 별을 반대로 누르지 않도록, 재조회가 실패하면 상태 확인을 먼저 요구한다.
Repository는 요청 전·토큰 갱신 후·응답 후 계정을 확인하고 취소된 요청의 늦은 결과를 버린다.
목록/별은 메모리에만 있고 JWT나 북마크를 별도 기기 저장소에 복제하지 않는다.
