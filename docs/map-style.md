# 지도 스타일 (네이버 Map Style Editor)

내 주변 화면의 지도를 앱 팔레트로 칠한 값. **콘솔에만 있으면 스타일이 지워졌을 때
되살릴 수 없어서** 여기 적어 둔다.

> 스타일은 NCP 콘솔에서 만들고 앱은 ID 로만 받는다.
> `local.properties` 의 `daengs.naverMapStyleId` — 없으면 기본 네이버 지도로 뜨고
> 앱은 정상 동작한다 ([README](../README.md) 참고).

## 어디서 하나

콘솔 → Services → Application Services → **Maps** → **Style Editor** →
[지도 생성] → **라이트 테마** → 색을 주고 [Save] → [Publish] → 홈에서 **My Style ID 확인**.

**색은 전부 "색상 스타일링" 탭에서 한다.** 글자색도 여기다 — "글자 스타일링" 탭에는
폰트 종류·크기·아이콘 크기만 있고 색이 없다. 이걸 몰라서 한 번 헤맸다.

### 지하철 노선은 일부러 안 죽였다

한 번 회색(`#DDD2CE`)으로 눌렀다가 **되돌렸다.** 노선 색은 어느 선인지를 말하는
**정보**다 — 마커 여덟 색을 분홍으로 통일하지 않은 것과 같은 이유다. 배경이 크림으로
물러나고 나니 오히려 선이 더 또렷하게 읽혀서, 눌러야 할 이유가 없어졌다.

채도 높은 색이 지도 면적의 2.4% 인데 그게 노선과 우리 마커다. **그건 남겨야 하는 2.4%** 다.

### 밝기 층이 요점이다

**도로는 테두리(halo)를 못 준다.** 편집기에서 halo 가 있는 건 심볼뿐이라, 길과 땅은
**면 밝기 차이로만** 구분된다.

처음에 육지를 앱 배경과 같은 `#FDF4F0` 으로 두고 도로를 흰색으로 했더니, 화면을 재보니

```
#FBF5F2  28.1%  ← 이면도로
#FDF4F0  23.2%  ← 육지
밝기 차이 0.001    ← 사람 눈에 같은 색이다
```

**지도인데 길이 안 보였다.** 육지를 한 단 내려서(`#F2E4DC`) 어두운 쪽부터
**건물 → 단지 → 육지 → 이면도로 → 주요도로** 순으로 층을 만들었다. 지금은 가장 넓은
두 면의 밝기 차이가 **0.060** 이다.

값을 손볼 때 이 순서가 깨지지 않게 한다. 지도 배경을 앱 배경과 똑같이 맞추고 싶어지는데,
그러면 그 위에 얹을 흰 도로가 갈 자리가 없어진다.

## 편집기 제약 (겪은 것)

- **일괄 적용이 없다.** 색이 Mediator 하나씩만 먹는다. Feature 전체 버튼도 대표색도
  없다. 그래서 다 칠하지 않고 **면적 큰 것 열몇 개만** 칠한다
- **halo 는 심볼에만.** 도로·건물·육지는 본색 하나뿐이다
- **심볼 색상은 일부만 된다(△).** 색이 안 바뀌는 글자가 있고, 그건 그대로 둔다
- **지하철 노선은 노선마다 Mediator 가 다르다.** 2호선을 바꿔도 수인분당선은 남는다.
  목록에서 찾지 말고 **캔버스에서 그 선을 직접 클릭**하는 게 빠르다
- 항목이 많은 Feature(심볼 107 · 시설 143 · 단지 29)는 전부 만지지 않는다.
  손으로 칠해 두면 저쪽이 항목을 늘렸을 때 우리 것만 어긋난다

## 앱에서 하는 것 — 스타일과 겹치지 않게

`map/provider/naver/NaverMapSurface.kt` 의 `applyDaengsStyle` 이다.

- 타일 오기 전 배경을 크림으로 (기본이 회색이라 지도 뜰 때마다 번쩍인다)
- 건물 높이 0 — 기울이지 않는 화면이라 3D 가 정보를 안 주고 마커가 묻힌다
- **밝기는 스타일이 있으면 0** 이다. 스타일이 이미 밝게 칠해져 있어서 여기서 또
  밝히면 물·녹지가 바랜다

**`symbolScale` 은 건드리지 않는다.** 지도 상호명이 우리 마커와 경쟁해서 줄여 봤더니
(0.5) 작아진 자리에 라벨이 더 들어차 오히려 복잡해졌고, 키우면(1.25) 글자가 우리
마커만큼 커졌다.

**지하철 노선은 앱에서 못 끈다.** `LAYER_GROUP_TRANSIT` 을 꺼도 그대로다 — 기본 타일에
그려져 있다. 지금은 살려 두기로 했으니 끌 일이 없지만, 나중에 누가 "이 선 좀 빼자"고
하면 **앱 옵션으로는 안 되고 스타일에서 노선마다 색을 줘야 한다.**
