# 산책 상세의 경로 백업 상태 (#330)

#327의 저장 영수증을 읽고, 문제가 있을 때만 산책 상세 상단 더보기 옆에 재전송 아이콘을 표시한다. GPS 경로 백업 상태이며
행동·사진·일기의 전체 백업 완료를 뜻하지 않는다. 표시 때문에 GPS 원본을 다시 계산하거나
서버 조회를 추가하지 않는다.

| 저장 상태 | 표시 |
| --- | --- |
| 원본 업로드/분석 미완료, 필요한 기본·정밀 업로드 미완료 | 숨김 |
| 정밀 업로드 완료, 기기 계산 대조 미완료 | 숨김 |
| 미지원 정책 또는 저장된 미완료 백업 오류 | 구름 아이콘 + 작은 오류 점, 누르면 재전송 요청 |
| 그 기록에 필요한 백업 및 검증 영수증 완료 | 숨김 |

옛 정책 없는 기록은 기존 derived 상태, 기본 백업만 가능한 복원 기록은 기본 완료 영수증을
기준으로 판단한다. 이 기록에 새로운 정밀 검증을 했다는 뜻은 아니다.
원본 출처가 있는 측정 기록은 정밀 업로드와 검증 시각·영수증이 모두 있어야 완료다.

세션·기본 백업·정밀 영수증은 같은 Room transaction에서 읽고, 세 표의 변경을 관찰한다.
현재 계정의 완료 산책만 표시한다. 계정 generation이나 sessionId 변경 시 화면 상태를 새로 만들고,
삭제·타 계정·진행 중 세션에는 아이콘을 표시하지 않는다.
아이콘은 22dp, 터치 영역은 48dp이며 기존 상단 행을 사용하므로 지도 높이가 줄지 않는다.
상시 안내 문구나 완료 배너는 표시하지 않는다.

전송 요청은 기존 WalkDeliveryScheduler의 해당 세션 작업을 예약한다. 네트워크 조건과
기존 대기 작업 순서를 따르며, 예약 접수 직후 백업 완료라고 표시하지 않는다.
요청 결과는 짧은 토스트로만 알리며, 접근성 설명에도 요청 중/접수/실패를 구분한다.
접수 후에는 아이콘을 흐리게 비활성화하고 완료를 뜻하는 체크 표시를 쓰지 않는다.
화면은 Room 영수증을 계속 관찰한다. 예약 중/접수 후 같은 상태의 중복 탭을 막고 예약 실패는 재요청 가능하다.
기존 전달 작업은 그 산책의 행동·사진 등도 함께 처리할 수 있지만 내부 완료 판정의 범위는 경로에 한정된다.

이번 변경은 추가 DB 이관·API 변경·v2 핀 활성화를 하지 않는다. #327 다음에 병합한다.
검증 대상은 WalkRouteBackupSourceTest, WalkRouteBackupStatusTest, WalkSessionDetailUiTest,
WalkDeliveryTest다. 앞의 두 클래스는 상태·계정·삭제·영속 상태 갱신과 요청/완료 구분,
뒤의 두 클래스는 상세 지도 배치와 기존 전송 예약 경계를 확인한다. 실기기 화면은 별도 확인이다.
