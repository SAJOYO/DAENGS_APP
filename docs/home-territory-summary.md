# 홈 점령 현황

PR #230은 기존 홈 UI에 얇은 점령 현황 행을 추가한다.

- 챗봇 아래 기존 산책 카드 상단에 핑크 전봇대, 점령 수, 점수, 순위 자리를 둔다.
- 행은 최소 48dp 터치 높이이며, 누르면 기존 시즌 현황 대화상자에서 상세·새로고침·산책 지도 진입을 제공한다.
- 산책 카드의 횟수·시간·거리 세 칸, 기존 색·배치, 오늘의 한마디와 지난 산책 진입을 유지한다. 평균 속도는 추가하지 않는다.
- 챗봇·미니룸·TODAY 날씨·지도 마커 원본은 그대로다. 홈 전봇대는 기존 24×24 Canvas 아이콘 체계를 따른다.

## 데이터

점령 수·점수는 선택 강아지의 기존 `ActivityRepository` 시즌 조회를 사용한다. 조회 실패·미집계는 0점으로 바꾸지 않는다. 로그인이나 강아지 선택 전에도 필요한 상태 안내를 표시한다.

현재 앱·서버 활동 API에는 순위 계약이 없다. READY 응답도 `순위 —`를 표시하고 상세에서 순위 미제공을 설명한다. 순위표 진입과 실제 순위는 서버 계약이 추가된 뒤 연결해야 한다. 시안의 12위를 앱 데이터로 넣지 않는다.

산책 집계와 날씨에 따른 오늘의 한마디 정책은 기존 구현을 사용한다.

## 확인 범위

`HomeSummaryUiTest`는 411dp·320dp 홈에서 챗봇 아래 점령 행, 기존 산책 세 칸과 오늘의 한마디, 현황·기록 진입 및 평균 속도 미표시를 확인한다. Compose 렌더는 `app/build/reports/home-summary/home-original-territory*.png`에 생성한다. 테스트의 점령·산책 수치는 렌더용 예시이며 실서버 값이 아니다.

연결 기기의 설치본은 Play 서명이며 저장소 debug 서명과 다르다. 개발 APK를 덮어쓸 수 없으므로 기존 앱 삭제 없이 기기 교체 설치를 진행하지 않았다. 실기기 최종 확인은 같은 배포 서명의 업데이트가 필요하다.
