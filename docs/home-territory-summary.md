# 홈 점령·산책 요약

PR #230은 기존 크림 배경·흰 카드·분홍 아이콘을 사용해 챗봇 아래 정보를 정리한다.

- 산책 카드 위 48dp 이상 클릭 행에 핑크 전봇대, 점령 수, 점수, 순위 자리를 둔다.
- 행을 누르면 기존 시즌 현황 대화상자에서 상세·새로고침·산책 지도 진입을 제공한다.
- 그 아래 오늘의 산책을 횟수·시간·거리·평균 속도 네 칸으로 보여준다. 큰 글씨 설정은 두 줄로 나눈다.
- 기존 산책 기록 진입은 `지난 산책`으로 둔다. 오늘의 한마디 영역은 제거하고 미니룸의 TODAY 날씨는 유지한다.
- 지도 마커 원본은 바꾸지 않는다. 홈 전봇대와 속도계는 기존 24×24 Canvas 아이콘 체계를 따른다.

## 실제 값과 미제공 값

점령 수·점수는 선택 강아지의 기존 `ActivityRepository` 시즌 조회를 사용한다. 조회 실패·미집계는 0점으로 바꾸지 않는다. 로그인이나 강아지 선택 전에도 필요한 상태 안내를 표시한다.

현재 앱·서버 활동 API에는 순위 계약이 없다. READY 응답도 `순위 —`를 표시하고 상세에서 순위 미제공을 설명한다. 순위표 진입과 실제 순위는 서버 계약이 추가된 뒤 연결해야 한다. 시안의 12위를 앱 데이터로 넣지 않는다.

산책 수·시간·거리는 기존 `WalkHistory.todayTotals()` 값을 사용한다. 평균 속도는 완료한 오늘 산책의 **총 거리(m) × 3600 ÷ 총 활동 시간(ms)**이며 개별 속도의 단순 평균이 아니다. 일시정지·기록 단절은 기존 요약에서 제외되고, GPS 기록 중 잠깐 정지한 시간은 포함된다. 기록이 없거나 활동 시간이 유효하지 않으면 `—`를 표시한다. 평균 속도 칸을 누르면 계산 기준을 읽을 수 있다.

## 확인 범위

대상 테스트는 `HomeWalkSpeedTest`, `HomeSummaryUiTest`, 기존 `WalkSummaryTest`다. UI 검사는 411dp·320dp 홈 배치, 카드 진입, 평균 속도 설명, 큰 글씨의 두 줄 배치를 확인한다. Compose 렌더는 `app/build/reports/home-summary/`에 생성한다. 테스트의 점령·산책 수치는 렌더용 예시이며 실서버 값이 아니다.

2026-09-09에 위 21개 검사와 `:app:assembleDebug`를 통과했고, 세 가지 크기·글꼴 렌더를 확인했다. 전체 테스트 스위트는 실행하지 않았다.

연결 기기의 설치본은 Play 서명이며 저장소 debug 서명과 다르다. 개발 APK를 덮어쓸 수 없으므로 기존 앱 삭제 없이 기기 교체 설치를 진행하지 않았다. 실기기 최종 확인은 같은 배포 서명의 업데이트가 필요하다.
