# 홈 점령 현황

PR #230은 기존 홈 상단 로고 옆에 작은 점령 현황을 추가한다.

- 상단 로고와 알림 사이 여백에 핑크 전봇대, 점령 수, 점수, 순위 자리를 둔다.
- 기존 알림 버튼과 같은 44dp 높이로 상단바를 늘리지 않는다. 눌러서 시즌 상세·새로고침·산책 지도 진입을 제공한다. 긴 문구는 두 줄까지 표시하고 전체 내용은 상세에서 읽는다.
- 세로가 짧아 상단바가 사라지는 가로 화면에서는 스크롤되는 카드 열에 표시한다.
- 산책 카드의 횟수·시간·거리 세 칸, 기존 색·배치, 오늘의 한마디와 지난 산책 진입을 유지한다. 평균 속도는 추가하지 않는다.
- 챗봇·미니룸·TODAY 날씨·지도 마커 원본은 그대로다. 홈 전봇대는 기존 24×24 Canvas 아이콘 체계를 따른다.

## 데이터

점령 수·점수는 선택 강아지의 기존 `ActivityRepository` 시즌 조회를 사용한다. 조회 실패·미집계는 0점으로 바꾸지 않는다. 로그인이나 강아지 선택 전에도 필요한 상태 안내를 표시한다.

현재 앱·서버 활동 API에는 순위 계약이 없다. READY 응답도 `순위 —`를 표시하고 상세에서 순위 미제공을 설명한다. 순위표 진입과 실제 순위는 서버 계약이 추가된 뒤 연결해야 한다. 시안의 12위를 앱 데이터로 넣지 않는다.

산책 집계와 날씨에 따른 오늘의 한마디 정책은 기존 구현을 사용한다.

## 확인 범위

2026-09-09에 사용자가 별도 테스트 앱에서 화면을 확인하고 **로고 옆 점령 표시·기존 미니룸 크기·원본 산책 카드** 방향을 확정했다.

`HomeSummaryUiTest`는 411dp·320dp 홈에서 점령 표시 전후의 미니룸 영역이 같은지 비교한다. 챗봇 위치, 기존 산책 세 칸과 오늘의 한마디, 현황·기록 진입 및 평균 속도 미표시도 확인한다. Compose 렌더는 `app/build/reports/home-summary/home-top-territory*.png`에 생성한다. 테스트의 점령·산책 수치는 렌더용 예시이며 실서버 값이 아니다.

기존 Play 설치본은 debug 서명과 달라 교체하지 않는다. 사용자 요청으로 `com.daengs.app.hometest` / `댕스 홈테스트`를 별도로 설치했다. 별도 패키징은 저장소 밖 Gradle init script와 앱 이름 리소스로 적용하며 기본·release applicationId는 변경하지 않는다. 테스트 앱은 로그인과 기록이 분리된 UI 확인용이며 실제 계정·점령 데이터 통합 확인은 별도로 필요하다.
