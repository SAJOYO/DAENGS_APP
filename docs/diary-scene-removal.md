# 일기 장면 삭제

산책별에서 열던 기존 일기의 장면 목록과 열린 장면 본문에 쓰레기통 아이콘을 둔다. 목록은 20dp, 본문은 22dp로 옆의 수정 아이콘과 크기를 맞추고, IconButton의 터치 영역과 ‘장면 N 삭제’ 접근성 설명을 유지한다. 확인창에는 장면 제목, 일기와 지도에서 제외된다는 설명, 취소/삭제 버튼을 표시한다.

삭제는 현재 계정의 완료된 산책에 속한 StoryboardDraft의 hidden 편집이다. Room 트랜잭션에서 최신 편집을 읽어 해당 장면의 hidden만 바꾸므로 이미 수정한 제목·본문·검토 출처와 다른 장면 편집이 보존된다. 원본 행동, 사진 파일, GPS와 거리·시간 집계는 삭제하지 않는다. 서버 원본 삭제 요청도 보내지 않으며, 기존 장면 편집과 동일하게 기기에 저장한다.

기존 일기 리더가 숨긴 장면을 제외하여 목록·지도 말풍선·장면 수·순서를 함께 갱신한다. 선택 장면이 사라지면 기존 선택 해제 경로를 사용하고 패널 높이를 유지한다. 같은 위치에 남은 장면은 계속 표시한다. 말풍선의 근접 묶음 정책은 이번 변경 범위에 포함하지 않는다.

저장과 삭제는 같은 실행 잠금을 사용한다. 실패하면 확인창과 오류를 유지하여 재시도할 수 있고, 처리 중 중복 실행과 확인창 닫기를 막는다. 계정 교체·산책 삭제·화면 종료 후 늦은 완료는 기존 상세 상태의 수명 관리로 무효화한다. 별도의 일괄 삭제나 복원 UI는 추가하지 않는다.

검증: 실제 Room의 저장·리더 재진입·사진/행동 보존·최신 편집 병합·계정/완료/발행 경계, 삭제의 실패/중복/취소 수명, 320dp 화면의 목록/본문 진입과 장면 번호/패널 유지, 기존 일기 열람 및 DesignLock 테스트를 실행한다. Galaxy S25의 별도 미리보기는 같은 화면과 동작에 가상 산책 데이터를 주입하며, 가상 변경은 화면을 나가면 초기화된다.
