# 산책 화면의 정보와 조작 배치

- 왼쪽 위에는 홈·화면 회전·톱니바퀴 설정을 한 묶음으로 둔다. 홈은 원 없는 집 아이콘이다.
- **순수 검정을 쓰지 않는다.** 어두운 색은 앱의 따뜻한 갈색(`DaengsColors.TextPrimary`)이다. 홈 아이콘만 검정이던 때는 같은 묶음 안에서 회전·설정과 색이 갈렸고, 산책 화면만 차갑게 보였다. 겹을 옅게 깔 때도 같다.
- 오른쪽 위에는 시간·`멈춤` 카드만 둔다. 좁은 화면에서는 왼쪽 도구를 세로로 쌓는다.
- **`멈춤`은 강조한다** (분홍 테두리 + 연분홍 바탕). 시간 카드 안에서 유일하게 누르는 것이고, **산책 종료가 이 버튼 뒤에만 있어서** 못 찾으면 산책을 끝낼 방법이 없다. 멈춘 뒤 뜨는 카드에 `산책 종료`가 있다.
- 설정은 시작 전에도 열 수 있다. 동선 색상 선택은 설정 안에서만 제공하며 속도계·완료 경로·지난 기록에 같은 설정을 적용한다. 지도 위에 별도의 색상 버튼을 두지 않는다.
- 기록 중·일시정지에는 작은 반원 속도계를 표시한다. 완료 경로는 숫자와 색상 띠로 된 척도를 사용한다. 시작 전에는 속도 표시를 숨긴다.
- 하단 도크 바로 위에는 전봇대 아이콘과 `점령지 보기`를 한 줄로 둔다. 켜져 있으면 분홍색 `점령지 숨기기`로 표시한다. 시작 전에는 시작 카드 위에 두고, 그 옆에 `산책 기록`을 둔다. 지난 산책을 보려고 새 산책을 시작할 필요는 없다.
- **산책 기록과 일기를 구분한다.** 시작 전의 `산책 기록`은 완료된 세션 목록으로 나가며 홈의 `지난 산책`과 같은 화면이다. 걷는 중 도크는 `이 산책에 남긴 것`을 연다. 일기는 장면을 선택·구성해 내보내는 결과물이며, 산책 기록의 별도 하위 기능으로 관리한다. 목록에 제목이나 장면이 있다는 이유만으로 세션 목록을 일기라고 부르지 않는다.
- 하단 도크는 사진·행동 기록·일기·내 위치이고 한 칸이 58dp 다 (걸으면서 누르는 자리라 48dp 로는 자주 빗나간다). 가로 화면에서는 도크와 점령지 토글을 함께 오른쪽 아래에 배치한다. 속도계는 화면 하단 정중앙에 고정한다. 점령지 토글은 오른쪽 아래 도크 바로 위에 유지한다. 속도계 높이는 하단 지도 여백에, 도크 너비는 오른쪽 여백에 반영한다.
- 일시정지 메뉴에서도 홈·회전·설정을 왼쪽에 함께 둔다.
- GPS는 같은 크기의 8dp 점으로 표시한다. 초록은 양호, 노랑은 불안정, 빨강은 위치 사용 불가·확인 필요다. 점을 누르면 상세 설명을 볼 수 있다.
- 도구 선택색은 분홍으로 통일한다. 지도 여백은 실제 패널 크기를 측정해 반영한다.
- **분홍 바탕에 흰 글자를 얹지 않는다.** 이 저장소의 분홍은 밝아서 2.4:1 밖에 안 나온다. 연분홍 바탕에는 진한 갈색 글자를 쓴다(8.8:1). 분홍 글자를 연분홍에 얹었을 때 `그만두기`가 눌리지 않는 버튼처럼 보인 적이 있다.

GPS·시간 누적·일시정지 상태 전이·점령 판정·기록 저장 정책은 변경하지 않는다.

속도계 초안은 현재 GPS 속도를 사용한다. 바늘은 650ms 동안 표시만 보간한다. 속도가 없거나 8초 초과 지연·50m 초과 위치 오차가 있거나 일시정지하면 마지막 수신 숫자와 바늘을 유지하고 고정된 노란 경고등만 켠다. 숫자·단위·바늘·경고등 공간은 항상 유지한다. 첫 수신 전에는 0.0과 경고등을 표시하며 접근성 설명에서 측정 전 초기값임을 구분한다. 다시 수신하면 현재 값으로 갱신하고 경고등을 흐리게 표시한다. 경로 색상은 구간 거리/시간으로 계산하므로 현재 GPS 속도와 순간적으로 차이가 날 수 있다. 실제 산책의 바늘 감도는 후속 확인 대상이다.

속도계 제목은 '속도'만 표시하며, 단위는 현재 숫자 옆에 작은 'm/s'로 붙인다.
검증: 지도 배치·점령지·설정·지난 기록 관련 테스트 25개 통과. 최종 도구 묶음과 단위 위치 변경 후 화면 배치 테스트 5개를 다시 통과했고 디버그 APK 빌드 및 Pixel 설치를 확인했다.
