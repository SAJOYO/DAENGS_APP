# 산책 화면의 정보와 조작 배치

- 왼쪽 위에는 홈·화면 회전·톱니바퀴 설정을 한 묶음으로 둔다. 홈은 원 없는 검정 집 아이콘이다.
- 오른쪽 위에는 시간·일시정지 카드만 둔다. 좁은 화면에서는 왼쪽 도구를 세로로 쌓는다.
- 설정은 시작 전에도 열 수 있다. 동선 색상 선택은 설정 안에서만 제공하며 속도계·완료 경로·지난 기록에 같은 설정을 적용한다. 지도 위에 별도의 색상 버튼을 두지 않는다.
- 기록 중·일시정지에는 작은 반원 속도계를 표시한다. 완료 경로는 숫자와 색상 띠로 된 척도를 사용한다. 시작 전에는 속도 표시를 숨긴다.
- 하단 도크 바로 위에는 전봇대 아이콘과 `점령지 보기`를 한 줄로 둔다. 켜져 있으면 분홍색 `점령지 숨기기`로 표시한다. 시작 전에는 시작 카드 위에 둔다.
- 하단 도크는 사진·행동 기록·일기·내 위치다. 가로 화면에서는 도크와 점령지 토글을 함께 오른쪽 아래에 배치한다. 속도계는 화면 하단 정중앙에 고정한다. 점령지 토글은 오른쪽 아래 도크 바로 위에 유지한다. 속도계 높이는 하단 지도 여백에, 도크 너비는 오른쪽 여백에 반영한다.
- 일시정지 메뉴에서도 홈·회전·설정을 왼쪽에 함께 둔다.
- GPS는 같은 크기의 8dp 점으로 표시한다. 초록은 양호, 노랑은 불안정, 빨강은 위치 사용 불가·확인 필요다. 점을 누르면 상세 설명을 볼 수 있다.
- 도구 선택색은 분홍으로 통일한다. 지도 여백은 실제 패널 크기를 측정해 반영한다.

GPS·시간 누적·일시정지 상태 전이·점령 판정·기록 저장 정책은 변경하지 않는다.

속도계 초안은 현재 GPS 속도를 사용한다. 바늘은 650ms 동안 표시만 보간한다. 속도가 없거나 8초 초과 지연·50m 초과 위치 오차가 있거나 일시정지하면 마지막 수신 숫자와 바늘을 유지하고 고정된 노란 경고등만 켠다. 숫자·단위·바늘·경고등 공간은 항상 유지한다. 첫 수신 전에는 0.0과 경고등을 표시하며 접근성 설명에서 측정 전 초기값임을 구분한다. 다시 수신하면 현재 값으로 갱신하고 경고등을 흐리게 표시한다. 경로 색상은 구간 거리/시간으로 계산하므로 현재 GPS 속도와 순간적으로 차이가 날 수 있다. 실제 산책의 바늘 감도는 후속 확인 대상이다.

속도계 제목은 '속도'만 표시하며, 단위는 현재 숫자 옆에 작은 'm/s'로 붙인다.
검증: 지도 배치·점령지·설정·지난 기록 관련 테스트 25개 통과. 최종 도구 묶음과 단위 위치 변경 후 화면 배치 테스트 5개를 다시 통과했고 디버그 APK 빌드 및 Pixel 설치를 확인했다.
