# 산책 화면의 정보와 조작 배치

- 시작 전에는 속도 범례와 색상 설정을 숨긴다. 기록 중·일시정지·완료 경로에는 함께 표시한다.
- 산책 시간과 일시정지/재개 메뉴는 왼쪽 위 카드에 묶는다. 거리·날씨·GPS는 그 카드 안의 보조 정보다.
- 홈·점령지 표시·화면 회전은 오른쪽 위에 묶는다. 380dp 미만에서는 도구를 세로로 배치해 시간 카드와 겹치지 않게 한다.
- 속도 범례의 색상 버튼은 동일 카드에서 설정창을 연다. 5단계 색상 정책과 설정 저장 방식은 유지한다.
- 하단 도크에는 사진·행동 기록·일기·내 위치만 둔다. 일시정지는 기존 Pause 액션을, 재개 메뉴는 기존 일시정지 화면을 사용한다.
- 지도 상단 여백은 새 상단 영역의 실제 측정 높이를 따른다.

GPS·시간 누적·일시정지 상태 전이·점령 판정·기록 저장 정책은 변경하지 않는다.

검증: 디버그 빌드 성공. WalkScreenPolicyTest(5), WalkTerritoryUiTest(11), WalkColorSettingsTest(1), WalkSpeedLegendTest(1), 총 18개 통과. Pixel_8 설치와 시작 전/기록 중 UI 배치를 확인했다. 공유 기기의 다른 작업과 화면 전환이 겹쳐 최종 지도 타일과 전체 일시정지/재개 흐름의 기기 시각 검증은 남아 있다.
