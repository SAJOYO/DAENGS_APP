# 전봇대 접근과 영역표시 피드백

[APP PR #155](https://github.com/SAJOYO/DAENGS_APP/pull/155). 기존 로컬 점령 연습의 판정 결과를 지도 위 짧은 효과로 전달한다.

## 화면 동작

| 상태 | 지도와 장소 카드 |
| --- | --- |
| 시작 전 | 점유 정보만 표시. 접근 링·발자국·성공 효과 없음 |
| 선택 장소에서 영역표시/인증 촬영 가능 | 링을 밝히고 마커를 최대 18% 키웠다가 700ms 안에 복귀 |
| 미인증 점유 확정 | 주황색 발자국과 링 강조, 최대 1100ms. 카드에는 미인증임을 표시 |
| 사진 인증으로 점유 확정 | 초록색 발자국과 링 강조, 최대 1100ms. 인증 완료 문구 |
| 사진 대기·통신 재시도·거절 | 각 상태 문구. 인증 성공 효과 없음 |
| 일시정지·선택 해제·점령지 숨김 | 진행 중 효과를 거둠. 멈춘 동안 확정된 결과를 나중에 성공 효과로 재생하지 않음 |

별도 팝업이나 자동 장소 선택은 없다. 링의 **반경은 기존 판정 반경 그대로**이며 색과 선의 밝기만 바뀐다. 성공 뒤 점유 색상은 유지하고 발자국만 사라진다. 선택 마커는 발자국과 겹쳐도 충돌 숨김으로 사라지지 않는다.

전봇대의 선과 내부 색은 보존하고 점유색을 테두리에 적용한다. 전체 아이콘을 단색으로 덮어 전봇대 모양이 원에 묻히는 것을 피한다.

후속 그림 교체에서는 원형 마커/테두리 대신 기본·점유 전봇대 에셋을 사용한다. 현재 그림 규격과 상태별 표시 기준은 [territory-pole-art.md](territory-pole-art.md)를 따른다. 이 문서의 링과 발자국 효과 정책은 유지한다.

## 상태와 재생

`TerritoryFeedbackTracker`는 ViewModel 생애 동안 세션별 원본 점유 상태를 관찰한다. 첫 조회를 성공으로 해석하지 않고 현재 산책에 귀속된 점유 변경에서만 성공 이벤트를 만든다. 사진 상태가 VERIFIED여도 점유가 확정되지 않았다면 성공 효과를 만들지 않는다.

준비 효과는 같은 산책/장소에서 한 번만 재생한다. GPS 흔들림, 일시정지/재개, 다른 전봇대를 봤다가 돌아오는 동작으로 반복하지 않는다. 새 산책에는 다시 허용한다. 이 제한은 **시각 효과만** 대상으로 하며 거리·점령·인증·재탈취 자격을 바꾸지 않는다.

이벤트는 ID와 monotonic 생성 시각을 갖는다. 화면을 재구성하면 남은 구간부터 재생하며 이미 끝난 이벤트는 재생하지 않는다. 지도 overlay는 효과 프레임마다 새로 만들지 않고 크기·색·투명도만 갱신한다. Compose의 유한 애니메이션을 사용해 시스템 애니메이션 배율을 따른다. 효과가 없어도 점유 색과 텍스트로 결과를 읽을 수 있다.

일반 산책 사진·기록·DB·온라인 API는 변경하지 않는다. 기존 VLM 판정은 여전히 페이크다.

## 검증

- 상태 전환: 준비 효과 중복 방지, 최초 점유 조회, 미인증→인증 확정, 대기/거절/재시도, 미확정 인증 결과, 다른 장소, 시작 전/일시정지/숨김, 새 세션, 유한 프레임 범위.
- ViewModel: 실제 영역표시 액션의 점유 변경과 지도 이벤트 연결, 레이어 숨김 때 제거, 반경 유지.
- Compose: 성공 문구 종료와 같은 이벤트 재구성, 사진 판정 상태별 문구, 시작 전/일시정지 카드, 기존 320dp/가로 배치.
- Preview: `TerritoryFeedbackPreview`는 지도 효과와 같은 벡터/프레임 값을 그리는 검토용 그림이다. `app/build/reports/territory-feedback/frames.png`는 이 Preview의 실제 Compose 렌더이며 Naver SDK 지도 스크린샷이 아니다.

```powershell
./gradlew.bat :app:testDebugUnitTest --tests 'com.daengs.app.map.features.territory.*' --tests 'com.daengs.app.ui.walk.*' --tests 'com.daengs.app.territory.*' :app:assembleDebug --console=plain
```

실기기가 없어 Naver SDK 위 효과의 실제 움직임·카메라 화면에서 돌아왔을 때의 감각은 기기 확인이 남았다. 설치 뒤 선택 전봇대에 접근 → 영역표시 → 사진 대기/확정 → 일시정지/재개 순서로 확인한다.
