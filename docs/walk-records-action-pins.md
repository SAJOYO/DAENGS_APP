# 셀로판 모아보기의 액션 핀

## 목표

셀로판 지도를 유지한 상태에서 킁킁·배설·짖기 액션 핀을 찾고, 기록 시각·강아지·해당 산책을
확인한 뒤 기존 세션·일기를 연다. 기존 행동 위치 전용 지도와 셀로판 지도가 분리되어
핀과 겹침 흔적을 함께 살펴볼 수 없던 연결을 완성한다.

## 표시·탐색 계약

- 같은 조회 조건에 해당하는 산책의 액션만 사용한다. 핀 표시 선택은 산책 수나 셀로판 농도를 바꾸지 않는다.
- 전체 흔적과 겹친 구간 위에 액션 핀을 올린다. 지도 표시 메뉴에서 핀 표시 여부·종류를 정한다.
- 동일 위치의 여러 액션은 건수로 묶고, 누르면 해당 기록 목록을 확인한다.
- 추정 위치는 기존 출처 문구를 유지한다. 위치가 없는 기록은 좌표를 만들지 않고 목록에서 열 수 있다.
- 산책 숨김은 해당 산책의 핀에도 적용한다. 핀을 통해 고른 산책의 동선은 기존 원본·속도색 정책을 쓴다.
- 카드의 산책 열기는 기존 세션·일기로 연결하며, 목록 복귀 때 탐색 상태를 보존한다.

## 구현

`walkRecordsActionPins`는 표시 대상 액션·동일 좌표 묶음만 계산하고 원래 산책 집합을 줄이지 않는다.
`WalkRecordsOverview`가 기존 `composeWalkRecordsMapScene`에 markers를 함께 넘겨
셀로판·동선·핀의 표시 순서를 유지한다. 기본 모아보기와 행동 조건으로 좁힌 셀로판 모두 지원한다.

- 기본은 모든 액션 표시다. `전체 흔적 ▾` 또는 `겹친 구간 ▾` 메뉴의 액션 핀 표시·종류를 바꾼다.
- 지도 옆 `액션 N건`은 위치 없는 기록을 포함한 액션 목록을 연다.
- 핀을 누르면 같은 위치의 목록을 기존 하단 패널에 표시한다. 여러 기록 중 하나를 고르면
  그 산책의 원본 동선을 강조하며, `이 산책 보기`는 기존 세션·일기를 연다.
- `모든 액션`과 `산책 목록`으로 기존 목록에 복귀한다. 산책별 세션 카드의 동작은 그대로다.
- `WalkRecordsActionPinState`는 상위 화면에 저장되어 상세 복귀와 상태 복원에 사용된다.
  새 조건은 탐색 상태를 초기화하고 기록 삭제·산책 숨김 시 오래된 핀 선택을 정리한다.
- 위치 비교는 저장된 좌표가 정확히 같은 경우에 묶는다. 추정 위치를 원본 GPS로 바꾸거나
  확대 배율에 따라 행동 횟수를 합산하지 않는다. 메모는 액션 핀 세 종류에 포함하지 않는다.

## 검증

조회 강아지·핀 출처·위치 없음·중복 위치·산책 숨김·표시 필터의 셀로판 독립성과
지도 핀→기록 목록→기존 산책 열기, 복원·갱신 후 오래된 선택 제거를 확인한다.
`WalkRecordsActionPinsTest`, `WalkRecordsActionPinsUiTest`, `WalkRecordsLabNavigationTest`와
기존 모아보기·동선·디자인 잠금 테스트를 함께 실행한다.
2026-09-13 최종 arm64 side-by-side debug 빌드와 관련 **123개 테스트**가 성공했다.

Galaxy S25 별도 미리보기의 가상 12회 산책은 액션 14건(위치 있음 11건·없음 3건)이다.
실제 NAVER 지도에서 셀로판 위 핀, 5건 묶음의 기록 목록, 선택 동선, 기존 세션 일기 열기를 확인했다.
실제 회원 서버 왕복은 이 가상 기록 화면 검증에 포함하지 않는다.
