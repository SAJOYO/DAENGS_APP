# 셀로판 모아보기의 액션 핀

## 목표와 승인안

셀로판 위에서 킁킁·배설·짖기 기록을 찾고 기존 산책 세션·일기로 이어진다.
2026-09-13 승인 HTML은 같은 길 밀집·동일 지점 반복·나란한 두 길을 비교했다.
묶음은 **기존 귀여운 행동 아이콘 + 오른쪽 위 작은 숫자 배지**로 표시한다.
1건은 아이콘만, 여러 건일 때만 배지를 붙인다. 메모는 세 액션 종류에 포함하지 않는다.

## 표시·탐색 계약

- 산책 조회 조건에 해당하는 기록만 사용한다. 액션 검색은 산책 수와 셀로판 농도를 바꾸지 않는다.
- 지도 위 종류 칩이 액션 검색의 유일한 진입점이다. 표시 메뉴에는 핀 표시 토글만 남긴다.
- 액션 전체 상태는 25% 먹색의 작은 점으로 존재를 표시한다. 한 기록을 선택하면 그 핀을 강조한다.
- 종류를 검색하면 해당 행동 아이콘을 선명하게, 다른 종류는 18% 먹색의 작은 배경 점으로 표시한다.
- 배경 점도 근접 묶음으로 줄이되 건수에 따라 커지거나 짙어지지 않는다. 배경은 터치를 받지 않는다.
- 조회 조건 밖·숨긴 산책·위치 없는 기록은 배경 점에도 표시하지 않는다. 위치 없는 기록은 액션 목록에서 연다.
- 순서는 셀로판 → 배경 핀 → 동선 → 결과 핀 → 선택 핀이다. 동선은 기존 원본·속도색을 유지한다.

## 밀집 묶음

`clusterRecordPins`는 NAVER projection을 dp로 변환한 좌표를 사용한다. 결과 묶음의 모든 점 쌍이
44dp 이내여야 한다. 인접 핀을 계속 이어 길 전체를 합치는 방식이 아니다. 배경은 30dp 범위다.
지도가 멈추면 현재 확대·회전·기울기의 projection으로 다시 계산한다. 제스처 중에는 기존 SDK
마커가 지도와 함께 움직이고, 카메라 정지 때 새 묶음과 배지를 배치한다.

- 배지 수는 검색한 액션 기록 수다. 다른 행동이나 산책 세션 수를 합쳐 표시하지 않는다.
- 확대해 위치가 떨어지면 묶음이 나뉜다. 정확히 같은 좌표의 반복 기록은 계속 한 묶음이다.
- 묶음 대표 위치는 구성원 중 실제 좌표다. 배지가 충돌하면 가까운 빈 자리로 이동하고 실제
  대표 위치까지 안내선을 그린다. 이 선은 동선·방향·통계에 들어가지 않는다.
- 가까운 두 길은 축소 시 함께 묶일 수 있다. 길 관계를 추정하거나 GPS를 길 위로 보정하지 않는다.
- 묶음 클릭은 하단에 해당 기록을 열고, 공간적으로 나뉠 수 있으면 `구간 확대`를 제공한다.
  확대는 명시적 버튼으로 실행한다. 서랍 높이 변경만으로 지도 전체를 다시 맞추지 않는다.
- 여러 좌표를 묶어 선택한 상태는 점선 범위로 표시한다. 한 기록을 고르면 해당 산책 동선을 강조한다.
- `이 산책 보기`는 기존 세션·일기 화면으로 연결한다. 산책별 카드 및 완료 산책 열람 정책은 유지한다.

## 구조와 복원

`walkRecordsActionPins`가 검색 결과와 배경 기록을 분리하고, 기존 장면 조립으로 전달한다.
`MomentMarkerState.recordPin`은 모아보기 전용 opt-in이다. 기존 일기 마커는 기존 렌더러를 사용한다.
`NaverRecordActionPinLayer`는 지도 크기를 받아 projection·묶음·작은 배지·배경 층을 담당한다.
아이콘은 기존 벡터와 `actionMarkerBitmap`을 사용한다. 새 비트맵 에셋을 반입하지 않았다.

`WalkRecordsActionPinState`는 선택한 기록 키 목록을 저장한다. 확대할 때 묶음 ID가 바뀌어도
하단에서 읽던 기록 집합을 유지하며, 상세 복귀·상태 복원에도 종류/선택/스크롤을 보존한다.
종류 변경은 이전 묶음 선택을 초기화한다. 삭제·산책 숨김 시 유효하지 않은 선택을 정리한다.

## 검증

2026-09-13 최종 arm64 side-by-side debug 빌드 및 관련 **141개 테스트**가 성공했다.
Galaxy S25에 최종 APK 설치 `Success`를 확인했다. 실제 NAVER 지도에서 킁킁 84건 배지,
묶음→84건 목록, 서랍 열 때 100m 축척 유지, 명시적 확대 후 50m 축척에서 72건/12건으로
분리되는 동작을 확인했다. 기존 세션·일기 열기와 복귀는 UI 테스트에도 포함한다.

- `WalkRecordsPinClusteringTest`: 길 전체 연쇄 방지, 순서 독립, 확대 시 평행 구간 분리,
  동일 지점 반복, 배지 충돌 배치, 잘못된 projection 및 많은 분리 좌표.
- `WalkRecordsActionPinsTest`: 검색/배경 분리, 강아지 귀속, 숨김/표시 토글, 추정/위치 없음.
- `WalkRecordsActionPinsUiTest`: 종류 칩, 기록 열기, 동일/근접 묶음 저장 및 복원, 종류 변경 시 초기화.
- 기존 모아보기·동선·지도 층·디자인 잠금·미리보기→기존 일기 진입 검증을 함께 실행한다.

기본 미리보기는 기존 12회 산책/14개 액션을 유지한다. 다음 intent로만 밀집 가상 데이터
(12회 산책·144개 액션, 킁킁 84건)을 연다. 둘 다 Room·회원 서버에 쓰지 않는다.

