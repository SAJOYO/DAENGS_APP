# 산책 모아보기 표시 구조

셀로판의 농도, 선택 동선의 속도색, 지도에 붙이는 순서를 서로 다른 정책으로 다룬다.
산책별은 한 세션의 기록·일기를 여는 목록이며, 모아보기의 표시 정책을 적용받지 않는다.

## 데이터에서 지도까지

```text
산책 원본 셀 → WalkTraceOverlap (서로 다른 세션 수·관련 산책 근거)
            → PreparedWalkRecordsTraces (재사용할 마스크)
            → TraceDisplayPolicy (농도 단계·먹색) → 합친 타일

선택한 세션 → WalkRecordsSource.loadRoute (원래 위치·시각)
            → WalkRouteAppearance (속도 정책·테마·선·테두리)

합친 타일 + 선택 동선 + 행동 위치
            → composeWalkRecordsMapScene → MapScene.walkPresentation
            → NAVER 공급자의 명시적인 층 순서 → 실제 오버레이
```

- `WalkRecordsDisplayPolicy`는 Compose나 NAVER에 의존하지 않는다. 기본 농도는
  `TraceDensityScale.Default`의 4/12/22/34/46%이며 범례도 이 단계에서 생성한다.
  먹색 토큰 `#29252B`는 `ui/theme/Color.kt`에 둔다.
- `WalkTraceOverlap.visibleCellCounts`는 색이나 알파를 알지 못한다. 한 산책의 반복 통과와
  이웃 셀의 번짐은 횟수를 늘리지 않는다. 숨김은 표시 농도에 반영하며, 2·3·5회 겹침 조건과
  관련 산책 근거는 전체 조회 결과를 기준으로 한다.
- `WalkRouteAppearance`는 해석한 속도 정책·테마와 기존 선 14px/흰 테두리 2px를 전달한다.
  모아보기 renderer가 내부에서 다른 테마를 다시 읽지 않는다. 기존 화면은 호환 기본값을 쓴다.
- `composeWalkRecordsMapScene`은 모아보기의 장면 조립 지점이다. 색이 없는 셀로판은 거부하여
  이전 renderer의 분홍 기본색으로 조용히 바뀌는 것을 막는다. 행동 위치 모드도 이 지점을 쓴다.

## 준비·취소·재시도

`WalkRecordsMapPresenter.kt`의 상태 helper를 기본 모아보기와 행동 탐색에서 공유한다.
탭·조건·숨김·지도 카메라·목록의 저장 가능한 상태는 기존 화면 소유자에 남는다.

| 바뀐 입력 | 다시 하는 작업 |
| --- | --- |
| 선택 집합·셀·브러시 | 셀로판 마스크 준비 |
| 숨김·겹침 조건 | 해당 표시 합성 |
| 농도 단계 | 농도 필드 합성. 마스크와 동선은 재사용 |
| 셀로판 색 | 출력 RGB. 마스크·농도 캐시는 재사용 |
| 동선 테마 | 기존 경로 오버레이 색. 원본 재조회 없음 |
| 선·테두리 | 기존 경로 오버레이 외형. 좌표·속도 재계산 없음 |
| 선택 세션·기록 입력·원본 공급자 | 선택한 한 세션의 원본 조회 |

농도 캐시 키에 불변 `TraceDensityScale` 값을 포함한다. 외부에서 넘긴 목록을 수정해도
이미 만든 정책과 캐시 키는 변하지 않는다. 합성 결과 배열은 캐시와 분리한다.

셀로판 준비와 동선 조회는 별도 수명과 오류·재시도를 가진다. 셀로판이 실패해도 유효한
동선을 열 수 있다. 새 입력은 이전 표시 상태를 즉시 분리하고, 취소된 작업은 완료되더라도
게시하지 않는다. 원본 조회는 반환 세션 ID를 검증하며 원격 셀로판 갱신만으로 재조회하지 않는다.
행동 위치 지도는 셀로판 준비 완료 시 카메라 범위를 갱신하는 동안 기존 MapView를 유지한다.

## 쌓임과 검은색의 의미

`WalkLayerStack.RECORDS`를 `NaverWalkLayerOrder`에서 공급자 값으로 해석한다.
합친 셀로판 `-300000` → 동선 `-100000` → 지도 지명 `0` 기준 → 마커 `200000` 순서다.
산책마다 셀로판과 동선을 번갈아 붙이지 않는다. 먼저 모든 셀로판을 타일로 합친다.

느린 속도의 `#181818`과 미확인 속도의 `#8A8A8A`는 기존 속도 정책이다. 셀로판 색으로
동선을 덮거나 미확인 구간에 임의의 유채색을 주지 않는다. 썸네일 축약점으로 속도를 계산하지 않는다.

## 개발용 진단과 검증

별도 미리보기의 `WalkRecordsLabActivity`에서만 `WalkMapDiagnostics`를 공급한다.
상단 **층 진단**은 배경 지도·셀로판·동선·마커를 각각 끄고 켠다. 카메라 입력과 조회 조건은
유지한다. 동선 끄기는 경로 끊김 점도 숨기며, 배경 끄기는 SDK의 빈 격자 배경을 사용한다.

붙어 있는 native 오버레이의 실제 global Z, 선/테두리 두께, 타일 SDK 알파와 픽셀 최대값을
읽어 보여준다. 정책 농도·동선 공급 경로·속도 테마·색 조각 중 미확인색 수도 함께 표시한다.
색 조각 수는 renderer의 보간 단위이며 GPS 점 수가 아니다. 오버레이 해제 시 진단 항목도 지운다.
좌표·계정 ID·세션 ID는 진단에 남기지 않는다. 일반 화면에는 진단 버튼이 없다.

회귀 테스트는 단계/범례 일치, 누락 색 거부, 농도 캐시 교체·원상복원, 테마와 셀로판의 독립성,
스타일 변경 시 원본/좌표 재사용, 셀로판 실패 중 동선 표시, 늦은 응답 거부와 재시도를 포함한다.
native 적용 adapter의 setter/readback 및 오버레이 해제도 검증한다.

2026-09-13 최종 `assembleDebug`와 관련 17개 클래스 **116개 테스트**가 성공했다.
`DesignLockTest` 7개를 포함하며 실행 범위는 [테스트 지도](../app/src/test/README.md)에 있다.

Galaxy S25에서 가상 12회 산책과 실제 NAVER 지도로 합친 화면, 동선만, 셀로판만 표시를 비교했다.
확인한 동선은 pink/14px/2px, 미확인색 0개였고 셀로판은 SDK 알파 1.0·픽셀 최대 0.46이었다.
설치는 별도 `com.daengs.app.preview`의 `adb install -r` Success로 확인한다.
실제 회원의 서버 왕복은 이 가상 기록 화면 검증에 포함되지 않는다.
