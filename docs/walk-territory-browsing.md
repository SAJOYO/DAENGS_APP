# 산책 전 둘러보기와 선택 장소 액션

APP PR #148. 최신 산책 기록 구현(dev 7e0899a)에 Geo PR #236 / 23cbecb의 화면 흐름을 이식한다.

## 상태와 행동

- 시작 전: 전봇대 표시를 켜고 명시적으로 선택한 장소의 점유 강아지와 인증 상태를 읽는다. 강아지 선택·점령·촬영과 접근 링은 없다.
- 산책 중: 선택 장소에만 강아지 선택·접근 안내·점령·인증을 표시한다. 첫 참여견을 기본값으로 쓰며 이후 선택을 기억한다. 같은 세션/장소의 시도가 생기면 그 시도의 강아지를 고정한다.
- 일시정지: 메뉴에서 지도 둘러보기를 선택할 수 있다. 점유 정보와 재개 안내는 유지하고 게임 액션은 숨긴다. 도크의 재개는 기존 계속/종료 메뉴를 연다.
- 닫기·빈 지도·표시 숨김은 선택을 해제한다. 가까운 장소 자동 선택을 제거했다. 선택한 장소를 보며 산책을 시작할 수 있다.
- 지도 표시는 별도 산책 세션을 만들지 않는다. 산책 기록 마커를 함께 유지하고 기록 상세·편집은 기존 Room 기반 WalkEntryEditor로 연결한다. 완료 후 기록 목록도 유지한다.

## 화면과 지도

GPS는 HUD 안의 색상 점과 `!`로 표현하고 눌렀을 때 상세/설정을 연다. 전봇대·회전 아이콘을 지도 도구로 묶고, 기록·일기·내 위치·쉼은 48dp 터치 영역의 도크로 묶는다. 기록 입력은 펼쳐서 사용한다. 시작 카드의 참여견 선택은 접을 수 있다.

점령 카드와 HUD 크기를 측정해 Naver SDK의 content padding으로 전달한다. 세로에서는 카드/도크 위, 가로에서는 왼쪽 카드와 오른쪽 도크 사이에 지도 중심을 둔다. 장소 선택 시 현재 위치와 선택 지점을 함께 맞추고, 사용자가 지도를 밀면 자동 맞춤을 멈춘다. 이 맞춤 상태는 내 위치 추적과 별개이므로 먼 동네의 전봇대를 선택해도 조회 지역이 내 위치로 돌아오지 않는다. 내 위치 버튼은 맞춤을 해제하고 내 위치 추적을 재개한다. 인증 대기열은 한 줄 요약에서 목록을 여는 방식으로 바꿨다.

## 유지한 경계

점령은 기존 debug 로컬 연습이다. 점유와 판정은 프로세스 메모리이며 VLM/온라인 공유를 붙이지 않았다. 실제 점유자 계정/프로필 조회 계약이 없으므로 웹의 합성 사용자 이름을 앱에 넣지 않는다. 현재 표시하는 것은 로컬 점유 강아지/인증 정보다.

일반 사진의 영구 저장·사진 Pin은 후속 [PR #151](walk-diary-photos.md)에서 연결했다. 온라인 업로드는 아직 없다. 전봇대 인증 촬영은 기존 CameraX와 페이크 판정 대기열로 연결된다. 접근 팝·반짝임·성공 발자국 효과도 후속 단계다.

## 확인

- 점령 컨트롤러: 명시적 선택, 시작 전/일시정지 접근 제한, 장소별 강아지 선택, 기존 시도 주체 고정, 셔터 시 세션/강아지/장소 재검증.
- ViewModel/지도: 미선택 상태의 점령 입력 차단, 토글 뒤 세션/점유 보존, 산책 기록 레이어 유지.
- Robolectric Compose: 시작 전→진행→일시정지 둘러보기, 강아지 선택 액션, 기존 기록 목록 진입, GPS 상세, 카드 닫기, 320dp/가로 카드와 도크 분리, 인증 목록 재시도.
- Compose 이미지는 `app/build/reports/walk-territory/*.png`에 저장한다. `showMap=false`의 실제 Kotlin 화면 렌더링이며 Naver SDK 지도와 실기기 화면은 아니다. PixelCopy가 이 환경에서 시간 초과되어 decorView를 Canvas로 그려 저장한다.
- 타겟 테스트와 debug APK 빌드를 수행한다. `adb devices`에 연결 기기가 없어 실제 지도·CameraX·보행·회전 생명주기는 아직 검증하지 않았다.

```powershell
./gradlew.bat :app:testDebugUnitTest --tests 'com.daengs.app.map.features.territory.*' --tests 'com.daengs.app.map.shell.MapScenePolicyTest' --tests 'com.daengs.app.ui.walk.*' --tests 'com.daengs.app.territory.*' :app:assembleDebug
```

## PR 리뷰 수정

시작 전 GPS가 산책 기록용 fix만 참조하던 문제를 수정했다. 화면 위치 구독과 추적 서비스에서 받은 최신 샘플을 같은 UI 상태로 전달하고, 시간·정확도·권한·모의 위치·수신 오류를 평가한다. 권한이 철회되면 샘플도 비운다. GPS 표시는 점령 접근 판정을 대신하지 않는다.

먼 동네 선택 후 조회/선택 유지, 지도 이동으로 자동 맞춤 해제, 내 위치 버튼의 추적 재개, 시작 전 수신과 권한 철회, GPS 경계값 및 Compose 녹색 점 표시를 회귀 검사에 추가했다.
