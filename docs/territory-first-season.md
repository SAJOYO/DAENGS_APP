## 현장 행동

- `first-season-rewards-v1`과 기존 `certified-protection-v2`는 촬영 전 photo-access 조회와 challenge 발급을 사용한다.
- 내 미인증 영역은 `유지 연장 · 0점`을 표시한다. 새 산책의 첫 접촉은 MARK의 서버 자동 연장으로, 같은 산책의 기존 claim은 `PUT /claims/{claim_id}/renewals/{renewal_id}`로 처리한다.
- 내 인증 영역은 `사진으로 유지 연장`을 제공한다. `PHOTO_RENEW`를 허용하며 이전 인증 성공 후에도 새 challenge와 새 사진으로 연장한다.
- 연장은 0점이고 기존 인증 보호 시각을 바꾸지 않는다. 인증은 GPS 오차를 포함한 10m, GPS 연장은 기존 MARK의 20m 조건이다.

## 요청 저장과 복구

Room의 기존 territory_operation에 RENEW 종류를 추가한다. DB 스키마 변경은 없다.
새 행동마다 UUID와 원본 위치 증거·장소 버전·claim을 최초 전송 전에 저장한다. 응답 유실 후에는 같은 UUID와 request 문자열을 재전송한다. 같은 장소에 미결 연장/사진이 있으면 추가 연장을 저장하지 않는다.

GPS 연장 영수증의 UUID·버전·만료 시각을 검사하고 요청을 확정한다. 그 뒤 claim을 다시 조회해 현재 점유를 표시한다. 영수증만으로 소유권을 되살리거나 새 점령 애니메이션을 내보내지 않는다. 현재 조회 실패는 이미 성공한 연장을 실패로 되돌리지 않고 다음 지도 조회에서 복구한다. 다른 로그인 계정의 요청은 전송하지 않는다. 사진 연장은 기존 인증 완료 피드백을 사용한다.

## 시간과 점수

- expires_at, season_id를 보존한다. 유지 시간은 server_now와 수신 후 단조 시계 경과로 표시한다.
- 표시상 만료 시점에는 점유를 확인 중으로 바꾸고 행동을 막는다. 앱이 중립화를 확정하거나 장소 버전을 올리지 않는다. 기존 15초 주기/재진입 서버 조회가 현재 상태를 확정한다.
- 새 시즌 조회에 이전 시즌 영수증의 점유를 덮어쓰지 않는다.
- base_bonus, takeover_bonus, final_rank를 보존한다. 구 응답의 누락/null을 0점으로 만들지 않는다. 홈의 기존 현황 상세에 기본/탈취/보유 내역을 표시하며 보유 점수는 서버 정수 누적 단위를 소수 첫째 자리까지 잘라 표시한다.
