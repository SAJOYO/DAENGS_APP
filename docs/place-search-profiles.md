# 시설 검색의 실제 프로필 선택

앱 [#147](https://github.com/SAJOYO/DAENGS_APP/pull/147), 서버
[#253](https://github.com/SAJOYO/DAENGS_dev/pull/253)의 연결 계약이다.

debug 앱의 홈 → 시설 검색에서 새 화면을 사용한다. release 기본 진입점은 이번에 전환하지 않는다.
fixture 검토판의 가상 프로필과 debug live의 계정 없는 고정 좌표 화면은 실제 계정 검증을 대신하지 않는다.

실제 `/app/pets` 목록을 PetHolder에서 받고, 현재 계정 ID와 함께 PlacesViewModel에 전달한다.
첫 선택은 비움이며 대표견이나 산책 선택을 자동 적용하지 않는다. 같은 이름도 ID로 선택하고
dialog에는 중복 이름 식별용 ID 끝부분을 함께 표시한다. farewell_on이 있는 개는 동행 목록에서 제외한다.

검색 화면 진입/선택 dialog 열기/목록 새로고침에서 프로필을 재조회한다. 로딩과 실패는 빈 목록과
다르며 선택을 보존하되 평가를 적용하지 않는다. 성공한 재조회에서 사라진 개는 선택에서 제거하고
안내한다. 로그아웃/계정 변경에서는 선택을 지운다. PetHolder의 늦은 재조회 응답도 generation으로 버린다.

선택 상태는 화면 ViewModel 세션에만 있고 디스크에 저장하지 않는다. 프로필의 체중/실제 생일과
updated_at을 값 스냅샷으로 만들며 family_day·미상·잘못된 값에서 나이나 체중을 추정하지 않는다.
크기 등급 입력은 현재 프로필 API에 없으므로 자동 추정하지 않는다. 새 선택/프로필 변경은 같은
지도 중심·반경·이름·업종·주차 정렬을 유지해 재검색하며 모든 업종 묶음에 같은 스냅샷을 보낸다.

Place는 ref/revision을 인증된 신원으로 취급하지 않는다. 앱이 인증된 목록에서 선택한 값이며
서버는 그 값만 평가한다. 프로필 원격 수정은 재조회 전까지 알 수 없으므로 항상 최신이라는 보증은 없다.
서버가 dogs를 무시하거나 echo/개별 평가가 빠진 경우 결과를 정상 평가로 표시하지 않고 오류로 처리한다.

펼친 카드는 선택한 반려견별로 체중/크기/나이의 평가 범위를 명시하고, 추가 동반 조건 원문과
출처·기준일·전화/길찾기를 함께 표시한다. 마릿수 등 복잡한 조건은 자동 판정하지 않으며
조건 불일치나 미상 때문에 시설을 자동 제외하지 않는다. 접힌 발자국 아이콘은 원천 등록 상태다.

검증은 APK 빌드, 상태/요청/응답/프로필/Compose 테스트로 수행한다. GPS·실제 계정·외부 앱·작은 화면과
접근성 시각 검증, 서버 배포와 release 전환은 별도다.
