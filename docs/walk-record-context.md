# 공백·전환과 기록 사건의 시간 관계

2026-09-12 · APP #343 · 완료 산책 화면의 4번 작업

지도에서 보행선 밖 관측 경로를 읽는 [#342](walk-observed-route-map.md)에 전후 관계를 연결한다.
동선 탐색의 ‘기록의 전후 관계’나 지도 경계를 선택하면 공백/전환 또는 시작/종료 상세가 열린다.
장면의 위치와 보행 합계를 변경하지 않는다.

### 장면 열람 정책 — 사용자 리뷰 반영

장면은 산책을 돌아보는 일기다. 장면 제목 아래 `17:00` 형식의 시각 하나만 남기며,
추가 기록 시각·이전/다음 관측 시각·중복 앞/뒤 장면 버튼·시작/종료 진단 버튼을 본문에서 제거했다.
위치 안내 문구에도 별도의 관측 시각을 반복하지 않는다. 시각 근거는 내부 판정과 진단에 보존한다.

공백은 장면 목록에 회색 원의 `–`와 `17:01–17:02 · 경로 공백` 제목으로 끼워 넣는다.
장면 번호·개수·편집·이전/다음 탐색은 실제 장면만 센다. 목록의 공백을 누르면 장면 탭 안에서
해당 양 끝에 지도를 맞추고 선택 전용 점선 및 짧은 설명을 보여준다. 시간 길이가 미확정인
공백은 목록 끝에 `시간 미확인 · 경로 공백`으로 남긴다. 실제 장면이나 핀을 생성하지 않는다.
목록에서 공백을 선택하면 접힌 패널에서 설명하고, 장면을 선택하면 펼쳐 읽는다.
아래 지도 선택 수정 전 debug 빌드 및 29개 클래스 190개 테스트 통과(실패/오류/건너뜀 0).
공백 선택→같은 장면 탭의 안내→목록 복귀→기존 번호의 장면 열람을 UI 테스트로 검증했다.

### 지도 선택 일관성 — 공백 표식과 장면 번호 겹침 수정

기존 지도 콜백은 목록과 같은 위치 이동 함수를 호출했다. 선택 종류에 따른 지도 여백 변경도
다시 fit/center를 실행했다. 공백 표식은 선택하면 `?`에서 긴 `경로 미확인`으로 커졌고,
같은 위치의 종료/마지막 확인 표식은 별도의 클릭 대상으로 그 위에 겹쳤다.

- 지도 장면·공백·전환·시작/종료 표식과 안내선을 누르면 선택과 내용을 바꾸되 카메라 요청,
  범위·중심·여백 및 현재 패널 높이는 유지한다. 목록 선택과 명시적 전체/확대는 위치로 이동한다.
- 카메라 여백은 마지막 명시적 이동 요청을 따른다. 새 표식 선택 때문에 재계산하지 않는다.
- 지도 공백도 고정 크기 회색 `–`로 표시한다. 선택은 색만 바꾸며 좌표·라벨·클릭 우선순위는 유지한다.
- 장면 번호는 좌표 위, 공백은 아래에 둔다. 공백과 1m 이내인 종료/확인/전환 표식은 지도에서
  중복 표시하지 않는다. 해당 사건과 시각 근거는 동선 탐색 목록에 유지한다. 선택에 따라 숨김을 뒤집지 않는다.

이 수정은 표시와 선택 처리에 한정한다. 보행 판정·경로·거리·원본 장면 대응은 변경하지 않는다.

검증: debug APK 빌드 성공, 관련 29개 클래스 194개 테스트 통과. 첫 실행에서 추가한 상태 테스트의
수동 경로 fixture에 관측 채택 근거가 없어 실패하여 실제 완료 읽기 fixture로 교체했다.
해당 6개 테스트 재실행과 앞서 통과한 나머지 188개 결과를 합한 수치다. 제품 코드는 재실행 중 변경하지 않았다.
지도 선택의 패널 높이 유지(접힘/펼침), 같은 장면의 목록 선택 시 펼침, 공백 비트맵의 선택 전후
외곽/크기 일치, 공백 위치의 종료 표식 중복 제거 및 사건 주소 보존을 검증했다.
카메라 콜백과 여백 의존성은 코드로 대조했다. 수정 APK는 별도 검토 앱에 설치 Success를 확인했고,
이번 수정 후 폰에서 탭 동작을 다시 실행한 것은 아니다.

## 원본과 표시 책임

`RecordContextReview`는 #342와 같은 legacy 읽기 및 표시 채택 결과를 사용한다. 이미 보행
edge가 소유한 원본 범위를 유지하고, 표시를 채택한 보조 관측 범위 밖의 연결을 공백으로 묶는다.
원본 순서로 인접한 공백을 묶으며, 보행/보조 경로가 실제로 맞닿는 집계 전환만 따로 표시한다.
고정 길이로 나눈 탐색 경계는 전환이 아니다. 새 장면이나 집계 원장을 만들지 않는다.

공백 양 끝은 해당 원본 경계 관측의 위치 품질이 usable일 때만 제공한다. 한 끝이 부적합하면
먼 관측이나 사진 위치로 바꾸지 않는다. 독립적인 사진 핀은 장면으로 계속 남지만 공백의
경로 연결 근거가 되지 않는다. 기존 보행선의 소유 범위 안에서 진단 판정과 충돌한 부분은
보행 결과를 보존하며 새 공백 선이나 중복 보조선을 그리지 않는다. 시각 기준 문제가 기존
보행 소유 범위 안에 있으면 별도의 ‘시각 기준 미확정’ 전환으로 노출하며 안내선을 만들지 않는다.

`RecordContext`는 제어 사건 또는 원본 범위이다. 위치마다 원본 seq/관측 시각을 남긴다.
시작/종료의 사건 시각, 첫/마지막 usable 관측, 기존 보행선 끝점은 각각 유지한다.
지도 범위는 이 확인 위치들에서 구하고, 사건 시각에 위치를 만들어내지 않는다.

## 공백 안내의 계약

`GapGuideCommand(contextId, beforePoint, afterPoint)`는 실제 경로와 별도 타입이다.
`RecordContextLayerState`의 선택 안내로만 전달하며 `PolylineOverlay` 점선으로 렌더한다.
[Naver 공식 API](https://navermaps.github.io/android-map-sdk/reference/com/naver/maps/map/overlay/PolylineOverlay.html)의
패턴 기능을 사용한다. 색과 문구도 보행선/보조 이중선과 구별한다.

- 공백 선택 전에는 양 끝 표시만 있다. 양 끝이 모두 확인되고 서로 다를 때 선택 안내를 만든다.
- 클릭은 동일한 공백 선택으로만 전달된다. 안내가 다른 보행선 검사로 넘어가지 않는다.
- 안내는 거리·누적거리·방향·장면 anchor·보간·재생 경로·화살표 충돌 경로의 입력이 아니다.
- 장면/구간/전환/재생 선택, 탐색 탭 닫기, 읽기 교체는 공백 선택을 해제하며 안내도 제거한다.
- 공백 시각이 불확실해도 원본의 전후 관계와 양 끝 위치는 표시할 수 있다. 시간 길이는 만들지 않는다.

지도 경계는 원본 위치에 유지한다. 회색 공백/전환 표시는 실제 길의 형태를 채우지 않고,
선택한 상세에서 앞쪽과 뒤쪽 이동 구분·확인 시각·연결하지 않은 근거를 설명한다.
목록에서 시작/종료 상세 선택 시 펼친 패널 높이를 예약하고, 공백은 접힌 패널 위에 양 끝을 맞춘다.
지도에서 누른 경우는 기존 카메라와 패널 높이를 유지한다.
일반 지도 탐색의 카메라 정책은 유지한다.

## 사건과 위치 없는 장면

공유 선택은 `Gap / Transition / Event`를 추가한다. 다른 장면이나 구간 선택과 함께 켜지지 않는다.
시작/종료 지도 표식은 ‘보행 시작/끝’ 및 ‘첫/마지막 확인’으로 표시하며 제어 사건 상세로 연결한다.
같은 위치에서 두 시각이 대응하면 원본 사건은 상세에서 각각 유지한다.

위치 없는 장면도 기존 시각 하나와 본문, 하단 이전/다음으로 읽는다. 공백은 장면 목록의
별도 회색 항목으로 연다. 어떤 안내도 장면 핀을 경로선이나 관계 점선 위로 옮기지 않는다.
사건과 관측 시각의 상세 대조는 동선 탐색에서 명시적으로 선택한 경우에만 제공한다.

## 시간 재생

지원되는 legacy 읽기는 활동시간 대신 **기록 시작부터 종료까지**의 시간축으로 탐색한다.
첫 관측 이전과 마지막 관측 이후에도 시간 주소는 존재하지만 커서는 없다. 기존 거리와
활동시간 집계는 그대로다. 지원되지 않는 읽기는 기존 재생 경로를 유지한다.

재생은 원본 연속성이 확인된 기존 보행 edge와 채택된 보행 제외 관측 edge만 사용한다.
긴 보행 보간(15초 초과), 공백, 미확정 관측은 커서를 숨긴다. 보조 관측의 재생은 보행 합산이
아니며, 공백 안내선의 양 끝을 따라 재생하지 않는다.

epoch 변경·중복/역전 시각·단조 시간의 불일치가 있으면 전체 정밀 시간 재생은 보류한다.
해당 원본 범위는 계속 선택할 수 있고 각 관측에 기록된 시각을 보여주되 공백 길이나 사건과의
정확한 시간 차이를 주장하지 않는다. 부분 epoch 재생을 새로 도입하는 작업은 이번 범위가 아니다.

개인 폴더에 보관하며 실행 결과와 실기기 확인은 PR 본문에 남긴다.

아래는 장면 열람 정책 수정 전 검증이다. 수정 후 결과는 PR 본문을 참조한다.

실제 GPS 수신 중단·여러 보행 구간·epoch 변경 사례는 아직 확보되지 않아 A의 미확정 경계 및 합성 fixture와 구별한다. 정상 장면과
보조 경로, 기존 계산의 보존을 확인한다. 선택 안내의 접근·해제·재생 금지 조건도 검증한다.

전체 기록 카메라, 화면 밖 장면 수와 전체 revision 갱신은 5번이다. API 측정 전환, 불변
측정 저장, 과거 본문의 거리 의미, B 270m와 확보 원본 271.531737m 차이는 별도로 남는다.

리뷰에 남겼다. 이번 검증 앱은 실제 완료 화면과 같은 표시·선택 컴포넌트를 사용하지만,
출시 앱의 바이너리·로컬 DB 전체 흐름까지 검증한 것은 아니다.
