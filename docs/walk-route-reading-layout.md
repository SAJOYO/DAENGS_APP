# 걸어온 길 하단 배치 (#417)

완료 산책의 첫 화면은 기존 장면 탭이다. 두 번째 탭의 표시 이름만 `동선 탐색`에서
`걸어온 길`로 바꾼다. 내부 탐색 상태와 저장 형식은 그대로 사용한다.

## 지도와 범례

`WalkSpeedLegend`를 공통 지도 영역에 한 번 배치한다. 장면, 걸어온 길, 재생 중 모두
동일한 범례를 유지한다. 패널을 접거나 탭을 바꿔도 지도와 범례를 재생성하지 않는다.

완료 산책에서는 `이동 속도 km/h`, 색상 스펙트럼과 숫자 눈금을 표시한다. 기본 눈금은
`0 · 3.6 · 7.2+`이며 최대치의 `+`는 그 이상을 뜻한다. 기존 지도 색상 정책을
그대로 구독하고 눈금과 접근성 설명을 m/s에서 km/h로 환산한다. 진행 중 산책 등 다른
사용처의 기존 m/s 눈금은 유지한다. 관측 경로 설명 버튼은 원래 조건대로 함께 제공한다.

## 하단 패널

- 시간순 기록 화면은 원형 재생/일시정지, 현재 시각, 이동 속도, 배속을 첫 줄에 배치한다.
  바로 아래 얇은 시간 막대, 체크포인트 점, 경과/종료 시간을 고정한다. 재생 전후 배치는 같다.
- 전체 보기와 구간 고르기는 기록 상세에 둔다. 선택한 범위의 수정/복귀 조작은 바로 접근한다.
- 경로 목록과 기록 시각·측정 설명은 `기록 상세`를 펼쳐서 본다. 옛 기록도 기본은 접힘이다.
- 지도에서 선택한 공백 설명과 통과 시각 선택은 상세를 펼치지 않아도 접근한다.
- 재생 불가 안내와 읽기 오류 안내는 숨기지 않는다.

상단 제목·강아지·시간·거리·평균 속도·온도와 장면 목록/본문은 변경하지 않는다.
서랍 세 높이와 최초 중간 높이, 기존 탭 전환 시 재생 정지 규칙을 유지한다.
GPS, 측정, 재생 엔진, 선택·복원 정책은 이번 작업에 포함하지 않는다.

## 검증 범위

`WalkSpeedLegendTest`는 기본 범례와 km/h 눈금의 환산·정책 갱신을 검사한다.
`WalkSessionDetailUiTest`는 장면→걸어온 길→재생→장면에서 범례 하나의 표시 위치와
지도 마운트 횟수를 확인한다. `WalkExplorerPanelUiTest`는 옛 기록의 상세 접힘,
기존 경로/관측/전후 관계 접근, 구간 조작과 320dp 큰 글씨의 읽기 공간을 확인한다.
기존 읽기·서랍·범위 복귀·지도 도구·디자인 잠금 검사도 관련 클래스만 선택한다.

Compose 미리보기 지도는 합성 화면이다. 네이버 지도 실기기 확인과 운영 회원 데이터
동작은 이 테스트 결과와 별도로 확인해야 한다.

## 추가 승인: 장면·행동 객체 (1~3단계)

완료 산책에서 일반 장면과 행동 핀을 경로 옆으로 분리하고 실제 위치 점과 연결한다.
시작·끝은 `산책 시작` / `산책 끝`의 둥근 네모 아래 세모 꼬리가 실제 좌표를 가리키도록 고정하며 일반 장면 번호/서술에서 제외한다.
기존 저장 내용은 삭제하지 않는다. 상세 배치/밀집 한계 정책은 [지도 표식 배치](map-marker-layout.md)를 따른다.

행동을 누르면 걸어온 길의 행동 기록 목록에서 해당 원본들을 시간순으로 읽는다. 목록은 세로로
스크롤하며 기록이 많다고 가로로 늘어나지 않는다. 일반 장면은 기존 묶음/본문 열람을 유지한다.

## 추가 승인: 시간순 기록 리플레이 (4단계)

기존 재생 위치와 배속·일시정지·슬라이더를 그대로 사용한다. 같은 읽기 스냅샷의 장면·행동을
재생 시간축으로 투영하고, 도착한 체크포인트를 지도 표식과 하단 읽기에 함께 반영한다.
다음 체크포인트 전까지 현재 내용을 유지하며, 시간을 뒤로 옮기면 미래 기록 강조는 해제한다.
동일 시각에는 장면을 먼저 두고 기록을 세로로 표시한다. 같은 행동 ID에서 만들어진 장면은
내용을 한 번만 읽되 원본 장면·행동 표식 ID는 모두 강조한다. 다른 기록끼리는 합치지 않는다.
이전/다음은 해당 시각으로 이동하고 재생을 멈춘다.

- 측정 기록은 원본 epoch/clock 주소를 우선한다. 시각만 있는 기록은 같은 epoch의 검증 가능한
  시계 구간으로 연결하며 일시정지·시계 변경·중복 시각을 임의로 이어 붙이지 않는다.
- 행동은 기록한 시각을 사용한다. 과거 위치를 사용한 핀의 위치 수집 시각으로 사건을 옮기지 않는다.
- 위치 없는 기록도 시각을 확인할 수 있으면 읽기에 포함한다. 시간 연결 실패는 건수를 표시하며 원래 목록을 보존한다.
- 기록 준비는 화면 밖 스레드에서 수행하고 현재 스냅샷과 일치하는 결과만 채택한다.
- 범위 재생은 범위 안의 체크포인트만 보여 준다. 전체 재생 시작·끝에는 짧은 이름만 표시한다.
- 재생 읽기 스크롤은 기존 목록 스크롤과 분리한다. 체크포인트가 바뀌면 새 내용의 처음을 보여 주며
  카메라, 서랍 높이, 상단 통계와 공통 속도 범례는 재생 이벤트 때문에 변경하지 않는다.

검증: `DiaryReplayTimelineTest`, `DiaryReplayReadingUiTest`와 기존 하단 패널/서랍/디자인 잠금 검사.

### 재생과 지도 선택 분리

지도에서 장면·행동·경로·공백을 선택하면 별도의 `DiaryReplayInspection`이 선택/분석 작업을 맡는다.
재생 시계와 이동 점은 계속 진행하며 하단은 선택한 내용을 유지한다. `재생으로 돌아가기`는
지금 재생 중인 체크포인트로 읽기를 복귀시킨다. 지도 이동/확대/전체 보기로 재생을 멈추지 않는다.
슬라이더 등 명시적 시간 이동은 일시정지하고 재생 읽기로 돌아간다. 단순 일시정지/배속 변경은
선택한 기록을 유지한다. 기존 장면 탭 전환·앱 백그라운드 전환 시 정지 규칙은 그대로다.

### 재생 위치 프로필

이동 표식은 이번 산책 참여 강아지의 사진을 흰 테두리 원형으로 표시한다. 기존 산책의
사진 → 견종 얼굴 → 발바닥 합성을 재사용한다. 참여한 대표 강아지가 우선이며 대표가 없으면
산책 기록의 참여 순서에서 확인 가능한 첫 강아지를 쓴다. 참여 정보가 없으면 발바닥이다.
현재 대표라도 이 산책에 참여하지 않았다면 대신 표시하지 않는다.

사진은 앱의 기존 `PetPhotoHolder`에서 전달한다. 사진 갱신은 같은 SDK Marker의 아이콘만
바꾸며 재생 시계나 좌표를 초기화하지 않는다. 기기의 실제 위치 오버레이와도 분리한다.

### 시안 09의 하단 플레이어 적용

큰 가로 재생 버튼을 48dp 원형 버튼으로 바꾸고 시간/이동 속도/배속을 같은 줄에 둔다.
재생 위치 슬라이더는 4dp 선과 14dp 손잡이를 사용한다. 기록 지점은 선 아래 작은 점으로
표시하고 밀집한 점은 같은 화면 칸에 한 번만 그린다. 개별 기록 이동은 접근성 이름을 가진
이전/다음 버튼과 기존 시간 슬라이더로 제공한다.

재생 전에는 산책 시작 카드를 보여 주며 기록 상세는 접힌 상태다. 재생 기록의 제목·시각과
이전/다음 아이콘을 같은 줄에 둬 최초 중간 높이에서 시각까지 보이게 한다.
선택한 기록의 재생으로 돌아가기도 작은 보조 조작으로 둔다.
원본 장면 본문과 기록 시각 표시는 유지한다. 기존 시간 범위 탐색 화면은 기존 조작을 계속 쓴다.

산책 시작과 산책 끝은 번호 없는 기록으로 남기고 실제 시작/종료 시각을 표시한다.
처음·마지막 GPS 시각으로 대체하지 않는다. 이전/다음 이동과 시간 막대에도 두 지점을 포함한다.
범위 재생에서는 범위 밖 시작·끝을 끌어오지 않으며 일반 장면 서술이나 원본 ID를 추가하지 않는다.

이동 속도는 현재 재생 좌표를 만드는 검증된 구간의 거리/시간 또는 기존 경로 파생 속도다.
km/h로 환산하며 배속과 무관하다. 측정 경로는 기록 시계를 사용하고 공백/근거 없음은 `–`로
표시한다. 재생 가능 여부나 위치 보간 정책을 바꾸지 않는다.
